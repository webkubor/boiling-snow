# 《沸腾之雪》宣发体系入口

这套目录只解决一件事：

`让宣发内容不再散落在聊天和临时文件里，而是能按平台、按素材、按工作流直接执行。`

## 一、主战场

当前主战场有三个：

- 小红书
- 微博
- 微信公众号

分工：

- 小红书：短视频传播、壁纸种草、人物吸粉
- 微博：更新播报、热点扩散、角色热词、情绪传播
- 微信公众号：角色创作心路、作者想法、情绪长文、项目情怀沉淀

## 三、使用规则

以后做宣发，统一按这个顺序：

1. 先看本文件，确认这条内容发哪个平台
2. 再进对应平台目录，确定标题、文案、节奏和发法
3. 再去 `素材入口.md` 找现成素材
4. 有现成图就直接用
5. 没有现成图，再去生成

## 四、执行原则

### 1. 先用现成资产

优先调用项目里已有内容：

- 角色锚点图
- 服化道图
- 场景参考图
- 神兵素材
- 正片截图
- 已有 15 秒短片

### 2. 不够再生成

只有当现成资产无法满足当前宣发目标时，才进入生成流程。

### 3. 宣发不是重做正片

宣发内容的目标是：

- 放大角色记忆点
- 放大世界观气质
- 放大作者人格

不是把正片原样搬运一遍。
