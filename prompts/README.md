# Prompts 收藏目录

说明：本目录只放“可直接复用的已验证Prompt”，不与剧情分镜文件混放。目前已按生成媒体类型（图片、视频）进行了分类。

## 📁 目录结构

### `视觉.md` (静态图片场景扩展)

包含网站首屏、大地图、背景原画所用的统一风格静态出图 Prompt 集合。

### `/videos` (动态视频预演/分镜)

- `夜惊鸿骑马冲阵15秒.md`：夜惊鸿骑马冲阵15秒（含参考图映射与角色锁定）
- `夜惊鸿碾压破阵15秒.md`：夜惊鸿碾压破阵15秒（高镜头密度与连续命中版）
- `顾栖月百丈漈Solo15秒.md`：顾栖月百丈漈Solo（背伞持笛、卡点高燃版）

## 维护规则

- 每条视频/图片 Prompt 必须包含：用途、参考图映射、角色/场景锁定、正式 Prompt 正文。
- 禁止只存“裸命令”无说明版本。
