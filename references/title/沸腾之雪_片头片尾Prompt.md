# 《沸腾之雪》片头片尾 Prompt 存档

## 片头 Prompt｜雪意成题

寒夜蛰伏，雪意暗涌。画面从绝对纯黑开始，无任何光源。随着清冷的弦乐与冰晶碎裂音效响起，画面中心开始浮现极淡的青白色粒子流，如极寒气流般缓慢翻涌汇聚，形成一道若有若无的雪色光带，光带边缘伴随细碎的冰晶与淡蓝寒雾，粒子密度逐渐提升，营造出“风雪欲来”的压迫感。

雪潮破局，笔意初现。粒子流突然加速，从雪色光带中爆发出一道贯穿画面的凛冽白光，如暴雪倾泻，瞬间撕裂黑暗。白光所过之处，“沸”字左侧偏旁“氵”化作冰晶雪滴飞溅成型，笔画边缘翻涌着淡蓝寒气，墨色由深黑渐变为青蓝，笔画内部流动着细碎的冰棱反光粒子，整体呈现出“冰刃破山”的动态张力。

雪意凝形，字体渐成。“沸”字成型后，画面右侧爆发出第二道更具冲击力的雪色光浪，从画面底部向上延伸，“腾”字的竖笔以“一雪腾空”的姿态骤然成型，笔锋裹挟气流腾空而起，末端带有冰晶星屑飞溅特效。“腾”字的横画与撇画以冰雪拖尾的方式从竖笔中衍生而出，笔画边缘伴随青白色的能量涟漪，整体呈现出“雪意凝形、力透纸背”的视觉效果，两个字的笔画在黑暗中相互呼应，形成强烈的视觉平衡。

锋芒毕露，特效叠加。“沸腾”二字完全成型后，字体表面开始浮现出流动的青白色辉光，辉光从笔画中心向边缘扩散，形成“雪潮环绕”的动态效果。同时，画面中开始飘落细碎的冰晶与淡蓝粒子，粒子在字体周围旋转、碰撞，产生短暂的能量爆炸特效，字体边缘的锯齿光效逐渐强化，整体亮度提升30%，营造出“锋芒毕露、势不可挡”的冲击力。

雪意渐浓，余韵悠长。“之”字以冰线勾连的方式从“腾”字笔锋处延伸而出，笔画纤细如冰丝脉络，边缘翻涌着淡蓝雪雾；“雪”字以厚重笔触骤然落下，如积雪成峰，笔画内部流动着青白雪光，与前两字形成刚柔对比。所有动态特效逐渐收敛，“沸腾之雪”四字的辉光稳定为柔和的青白色，粒子流停止流动，冰晶星屑缓缓飘落至画面底部消失。最终定格为：纯黑背景下，“沸腾之雪”四字以发光书法字体呈现，左侧“沸”“腾”笔锋凌厉如冰刃，右侧“之”“雪”厚重如积雪，字体下方偏左位置浮现出青白色竖排小字“凛冬重燃”，字体边缘带有细微的能量光晕，整体呈现出“雪意长存、余韵悠长”的终局效果。

运动强度：0.75。特效强度：0.85。色彩校正：青白色主色调，辅以墨黑与淡蓝点缀，对比度提升20%。全程固定镜头，聚焦画面中心，无运镜变化，突出字体本身的动态张力。

## 片尾 Prompt｜雪落归寂，余火未熄

终局无声，寒意回笼。画面从正片最后一帧自然熔入纯黑，残留的风雪环境音尚未散尽，黑暗中先只看见极少量青白色雪粒缓慢下坠，像大战之后仍未落定的余雪。画面中心没有立刻出字，而是先出现一缕极细的淡红余烬光丝，埋在黑暗最深处，明灭极弱，像被厚雪压住却还未熄灭的火。

余雪回卷，旧题反现。原本下落的青白雪粒忽然受无形气流牵引，开始逆向回卷，在画面中央形成一圈极淡的雪雾涡流。随着低沉的冰裂声与极轻的火星噼啪声同时响起，雪雾中逐渐浮现“沸腾之雪”四字的暗影轮廓。这一次不是片头那种锋芒毕露的爆发成字，而是像被风雪慢慢从黑暗里擦出来，笔画边缘带着碎雪、裂冰与极细的暗红余辉，冷暖在极低亮度中对撞，呈现出“雪压火脉”的克制张力。

火脉潜行，寒光定骨。“沸”“腾”二字内部不再是纯青白流光，而是在笔画深处隐约流过一丝极暗的赤金火纹，像冰层之下缓慢行走的地火，只在笔锋转折处短暂闪现；“之”“雪”二字则更厚重沉静，像真正压住万物的冬雪，笔画边缘附着细碎冰晶与低饱和蓝白光晕。字体整体亮度始终低于片头，控制在收束状态，不允许再出现爆发式强光，重心放在“压住，但没灭”。

余韵收束，留一句不死。四字完全显现后，周围雪粒停止旋转，开始缓慢下沉，像一场大雪终于落回地面。此时画面右下或下方偏左，浮现一行极小的题签字样：“雪可覆山，难熄心火。”字色不发亮，只以淡灰青或极暗冷白呈现，像刻在冰面里的旧句。随后整幅画面继续轻微降亮，只有“沸腾”二字深处那一缕若有若无的暗红火脉还在极慢地跳动一下，最后连火脉也被风雪盖住，画面归于纯黑。

运动强度：0.35。特效强度：0.45。色彩校正：以墨黑、青白、冷灰为主体，只允许极少量暗红或赤金作为“余火”点缀，总体对比度降低10%，亮度低于片头30%。全程固定镜头，无运镜变化，不使用大范围爆闪，不使用夸张粒子爆炸，以“收、压、藏”为核心。

## 片尾设计建议

这支片尾最合适的原因，不是它更华丽，而是它和片头构成了完整闭环：

- 片头是“雪中起势”，片尾是“雪中收势”
- 片头是“锋芒毕露”，片尾是“余火潜行”
- 片头强调“凛冬重燃”，片尾强调“雪压不灭”
- 这样才能把《沸腾之雪》里“冷外壳、热内核”的核心气质真正立住

如果后面你想把片尾做得更短，也可以只保留最后一句题签：

“雪可覆山，难熄心火。”
