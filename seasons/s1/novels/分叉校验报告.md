## ⚠️ 实质性分叉（需要统一口径）

### 分叉 1：叙事结构描述（WORLD.md vs 世界观总纲.md）

| | 说法 |
|---|---|
| GitHub `bibles/WORLD.md` | 「**倒序叙事**。第 1 集为结果态，第 2-7 集为成因回溯，第 8 集起为后局展开」 |
| GitLab `设定/世界观总纲.md` | 「**正文正序推进，旧案碎片倒灌**。以乾明十七年为长篇启动点，通过人物回忆、旧物与冲突逐层揭露二十年前的根因」 |

**影响**：视频是倒序，小说是正序——这是**载体差异，两边各自成立**，但 WORLD.md 当前描述读起来像"全项目倒序"，建议 WORLD.md 补一句"（视频版）"限定，避免 Agent 误用。

### 分叉 2：慧明的身份（连城寺 vs 青莲寺）

| | 说法 |
|---|---|
| GitHub `cast/慧明.json` | 「连城寺首座 / 天下第一防线」 |
| GitLab `人物小传/慧明.md` | 「**无名小寺出身** → 后创**青莲寺**」 |
| GitLab `设定/天榜排行.md` | 「无名小寺和尚 / 后创青莲寺」 |

**影响**：⚠️ **实质性冲突**。GitHub 的"连城寺"在 GitLab 无出处；GitLab 明确"早期无名小寺，后期青莲寺"。**以 GitLab 为准**（小说库更新、有细节支撑），需改 GitHub `cast/慧明.json`。

### 分叉 3：欧阳断木的别称（老瞎子 vs 身份归属）

| | 说法 |
|---|---|
| GitHub `cast/欧阳断木.json` | 「孤山守碑人 / 西燕失忆战神」 |
| GitLab `人物小传/欧阳断木.md` | 「孤山守碑人 / 上一代西燕战神 / **别称：老瞎子**」 |
| GitLab `设定/天榜排行.md` | 天榜第六 = 「**老瞎子**」 |

**影响**：⚠️ GitHub 的 WORLD.md 天榜列表里写「欧阳断木 (老瞎子)」，但 `cast/欧阳断木.json` 的 `天榜排名` 字段是「天榜第六 (Rank 06)」——名称 OK。**小分叉**：GitLab 强调别称"老瞎子"是江湖通用称呼，建议 GitHub 档案补一个 `别称` 字段。

### 分叉 4：天榜排行官方文件的引用口径
