# 顾栖月·被救后关键时间线

来源：用户直接确认
状态：可作为人物时间线与王府线关系校验依据
适用范围：顾栖月 / 苏梦城 / 萧烬弦 / 夜惊鸿身份揭示线

## 时间线主干

被苏梦城救（黑发）
→ 学武
→ 苏梦城送玉笛
→ 学成闯江湖

【江湖期间】
苏梦城救萧烬弦
→ 受伤
→ 一夜白发
→ 变成白发王爷状态

随后：
顾栖月回王府
→ 第一次看到白发苏王爷
→ 此时萧烬弦已在王府

再往后：
顾栖月自己慢慢发现：夜惊鸿 = 苏梦城

## 结构化拆解

### 第一阶段：救下与重塑
- 苏梦城救下顾栖月时，苏梦城仍是黑发状态
- 顾栖月随后进入学习阶段
- 苏梦城在这一阶段送出玉笛【玉尘】
- 顾栖月学成后离开，开始独自闯江湖

### 第二阶段：顾栖月不在场期间发生的关键事件
- 顾栖月闯江湖期间
- 苏梦城去救萧烬弦
- 救人过程中苏梦城重伤
- 随后发生一夜白发
- 苏梦城进入白发王爷的人生状态

### 第三阶段：回王府后的认知变化
- 顾栖月回到王府
- 回府后见到的已经是白发状态的苏王爷
- 此时萧烬弦已经在王府之中
- 顾栖月不是立刻知道夜惊鸿身份
- 而是在之后相处和观察中，慢慢确认夜惊鸿就是苏梦城

### 第四阶段：花案外派
- 苏梦城开始追查母亲被宫里人下毒手的真相
- 线索落在“一朵花”上
- 顾栖月被派出去查这朵花背后的来源与宫中指向
- 这一阶段，苏梦城身边几名能直接调动的高手都不在身侧
- 因此外部风浪真正压来时，王府会呈现“人手空窗”的状态

## 校验重点

后续写人物关系、回忆戏、章节时间线时，必须遵守：

1. 顾栖月认识和被救时，对应的是黑发苏梦城
2. 顾栖月闯江湖，与“苏梦城救萧烬弦 / 一夜白发”在时间上是重叠或前后衔接关系
3. 顾栖月回王府时，看到的是白发王爷，不是黑发版本
4. 顾栖月先回王府，后慢慢确认夜惊鸿=苏梦城
5. 萧烬弦入王府时间，早于顾栖月确认夜惊鸿身份
6. “花案外派”发生后，顾栖月不在王府，不能写成她在这一节点陪侍苏梦城
7. 王府高手阶段性不在场，是苏梦城后续必须亲自顶上的关键原因之一
