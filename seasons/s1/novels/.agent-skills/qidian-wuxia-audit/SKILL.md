     6|# 起点中文网武侠投稿专项审核器
     7|
     8|## 目标
     9|不只判断“写得好不好”，而要判断：
    10|- 能不能挂在起点读下去
    11|- 有没有武侠辨识度
    12|- 有没有追读驱动
    13|- 有没有审核风险
    14|
    15|## 核心检查
    16|
    17|### 1. 开篇留存检查
    18|- 前100字是否有异样/命令/危险/冲突
    19|- 前300字是否出现人物+动作 或 人物+悬念
    20|- 前800字主角是否主动推进一步
    21|- 前1500字是否给出一次明确兑现
    22|
    23|### 2. 主角有效性检查
    24|- 主角是否有判断
    25|- 主角是否有手段
    26|- 主角是否有魅力
    27|- 主角是否主动改变局势，而不只是被局势拖着走
    28|
    29|### 3. 武侠辨识度检查
    30|每章至少落一项：
    31|- 兵器
    32|- 身法
    33|- 拆招
    34|- 江湖规矩
    35|- 门派旧怨
    36|- 名号压力
    37|
    38|### 0. 字数底线检查
- 《沸腾之雪》正文章节（不含序幕）默认不少于 2000 字
- 低于 2000 字默认判定为“章节功能未完成”，除非用户明确要求短章
- 2000-2600 字：可发布下限
- 2600-3500 字：当前推荐舒适区

### 4. 爽点兑现检查
- 本章有没有即时满足感
- 是否至少兑现一个小结果
- 是否只是铺局不落子

### 4.5 情绪与活人味检查
- 是否至少给出一个可记住的情绪点：鼻酸 / 发热 / 失而复得 / 死地前松一口气
- 高压章节里是否保留一点活人气：老兵粗话 / 同袍互损 / 黑色幽默 / 死地前浑话
- 幽默是否来自人物处境，而不是现代网梗抖机灵
- 夜惊鸿这类压场人物是否仍保持克制，避免碎嘴塌气场

### 5. 追读检查
- 章尾是否形成连续阅读冲动
- 下一章问题是否清晰
- 是否只有意境，没有动作后续

### 6. 商业化标题检查
- 是否适合推荐位点击
- 是否含有具体卖点
- 是否避免空泛标题

### 7. 平台禁线检查
重点排查：
- 政治敏感映射
- 淫秽擦边
- 极端暴力血腥堆砌
    58|- 现实民族/群体风险表达
    59|- 价值导向失衡
    60|
    61|### 8. AI味/模仿味检查
    62|- 是否过像某头部爆款
    63|- 是否有模板句堆砌感
    64|- 是否存在“漂亮但空”的AI腔

## 禁止项
- 禁止连续两章只铺局不落子
- 禁止主角连续两章没有主动行为
- 禁止整章最大价值只有氛围感
- 禁止靠隐藏身份反复单线程吊胃口
- 禁止战斗只有“快狠冷重”，没有判断与变化
- 禁止朝堂戏长期压过江湖戏
- 禁止章末只有意境，没有动作后续
- 禁止明显模仿头部作品句式
- 禁止全章只有高压，没有活人气与情绪起伏
- 禁止把接地气写成现代段子合集或油腔滑调
