    59|    59|## 三、叙事结构原则
    60|    60|
    61|    61|### 1. 主线原则
    62|    62|- 正文主线：正序推进
    63|    63|- 旧案揭露：碎片倒灌
    64|    64|- 不用大段历史课式回忆
    65|    65|- 不用一上来就把二十年前讲透
    66|    66|
    67|    67|### 2. 正确的总时间结构
    68|    68|- 二十年前：老剑神那一代埋因
    69|    69|- 乾明十七年：局开始转，夜惊鸿真正进入天下视野
    70|    70|- 后面很多年：关系、误会、死亡、结仇逐步升级
    71|    71|- 最终：三绝绝战
    72|    72|
    73|    73|### 3. 第一卷定位
    74|    74|第一卷不是终局前夜，而是：
    75|    75|**旧局开门。**
    76|    76|
    77|    77|写的是：
    78|    78|- 欧阳狂徒压境
    79|    79|- 南楚无人敢接
    80|    80|- 寒江淮重新想起苏梦城
    81|    81|- 苏梦城借此局把夜惊鸿真正推入天下视野
    82|    82|
### 4. 前三章铁律
前三章的任务不是“把所有设定压进去”，而是“把门推开，把人立住，把读者留下来”。

必须满足：
- 优先聚焦苏梦城主线，但允许一章只完成一个清晰任务
- 必须有具体事件，不要纯氛围空转
- 前三章的核心目标是：
  - 第1章：开门，立王爷与局势
  - 第2章：起势，立旧部、身份反差与军心变化
  - 第3章：进关前，立战场判断与危险压迫
- 不要求前三章把世界观、三绝、旧债、王府、黑市、顾栖月、慕夕歌全部一次讲完
- 宁可少讲一点，也不要为了“交代清楚”把人物压成设定卡
- 进入具体场景后，优先落人物动作、反应、细节，再让设定慢慢渗出来
- 章尾只留风声、去向、动作、物件、未说破的消息
- 禁止在前几章为了赶进度，强行塞满人物和信息
- 禁止把“用户提出的点”机械拆单执行成任务清单式写作

一句话：
**前三章最重要的不是信息量，而是人物要活、局要紧、读者要想往下翻。**

    97|    97|### 5. 第一章章尾实战修正
    98|    98|- 可以写：旧屋重新亮灯、黑市风声起、有人今夜出城、某物被取出、某句话被顺着风递出去
    99|    99|- 不可以写：直接点明隐藏身份、直接报出隐藏名号、直接亮出银面/长枪等关键答案性物件
   100|   100|- 好的第一章结尾，不是“读者知道真相了”，而是“读者知道今晚要出大事，但还差半步没看见”
   101|   101|
   102|   102|### 6. 体量与切章修正
   103|   103|- 第一章优先控制在 2500-3200 字
   104|   104|- 若一章明显塞入两章内容，不要硬切一半后直接当第二章；必须把切出来的章节重写成独立完整章
   105|   105|- 第二章不能只是“第一章后半截残片”，必须有自己的推进、关系变化或新钩子
   106|   106|- 判断标准：删掉这一章后，人物命线是否少走了一步；若没有，就说明这一章还不够成立

   110|   110|## 四、项目硬约束
   111|   111|
   112|   112|### 1. 主角与核心人物
   113|   113|- 男主：苏梦城
   114|   114|- 女主：顾栖月
   115|   115|- 三绝：慕北歌、夜惊鸿、欧阳狂徒
   116|   116|- 慕夕歌是“因”，是导火索，不是长期主视角中心
   117|   117|
   118|   118|### 2. 身份关系
   119|   119|- 苏梦城 = 夜惊鸿（本质同一人）
   120|   120|- 但在乾明十七年前后，天下并不知道，寒江淮也未识破
   121|   121|- 外界合理认知应是：苏王爷暗地里养着/借着夜惊鸿这把刀
   122|   122|- 不能写成所有人很早就看穿
   123|   123|
   124|   124|### 3. 苏梦城关键线
   125|   125|- 父死
   126|   126|- 从军
   127|   127|- 战功赫赫封王
   128|   128|- 自愿自废武功表忠心
   129|   129|- 母亲被宫里人下毒手
   130|   130|- 一夜白头
   131|   131|- 追查毒案，线索落在“一朵花”上
   132|   132|- 欧阳狂徒连败南楚大将后，被寒江淮重新推上局面
   133|   133|- 皇帝只给他三千轻骑
   134|   134|- 夜惊鸿借这一局真正成名
   135|   135|
   136|   136|### 4. 顾栖月关键线
   137|   137|- 顾栖月认识和被救时，对应黑发苏梦城阶段
   138|   138|- 回王府时，见到的是白发王爷
   139|   139|- 她不是立刻知道夜惊鸿身份
   140|   140|- 某一阶段她被外派去查“花案”
   141|   141|- 这一阶段不能同时写成她留守王府陪侍苏梦城
   142|   142|
   143|   143|### 5. 慕夕歌关键线
   144|   144|- 慕夕歌下山时，苏梦城已经是白发状态
   145|   145|- 她与宁观尘线属于“近几年发生的事”，不是很多年前
   146|   146|- 她的死法细节可后补，但性质已定：她是孤山死局中的承灾者之一
   147|   147|
   148|   148|### 6. 王府与丹阳
   149|   149|- 王府在丹阳城，离宫门不过三条长街
   150|   150|- 这是南楚建国以来第一个、也是唯一一个设在京城的异姓王府
   151|   151|- 皇帝自封王后从未踏入苏王府半步
   152|   152|- 朝廷官员避之不及
   153|   153|- 丹阳百姓却普遍亲近苏王府
   154|   154|- 所以王府在京城具有双重地位：
   155|   155|  - 朝堂眼里的是非地
   156|   156|  - 百姓口中的有情之府

   160|   160|## 五、写作时的几个高级判断
   161|   161|
   162|   162|### 1. 什么时候解释
   163|   163|- 人物命已经卷进去时再解释
   164|   164|- 没卷进去时，只给异样，不给答案
   165|   165|
   166|   166|### 2. 什么时候写世界观
   167|   167|- 不单独讲
   168|   168|- 借战报、路程、城池、官话、旧物、人物偏见慢慢露
   169|   169|
   170|   170|### 3. 什么时候用回忆
   171|   171|只在三种情况用：
   172|   172|- 情绪被触发
   173|   173|- 物件被触发
   174|   174|- 对抗被触发
   175|   175|
   176|   176|### 4. 什么叫写歪了
   177|   177|一旦出现以下情况，基本就是歪了：
   178|   178|- 一章里解释太多
   179|   179|- 人物像设定卡，不像活人
   180|   180|- 章尾提前揭底
   181|   181|- 江湖写成玄幻
   182|   182|- 朝堂写成空泛宫斗
   183|   183|- 所有人都比读者懂得更多

   203|   203|
   204|   204|如果一章写对了，它应该同时满足：
   205|   205|- 读者先被人抓住，不是先被设定砸住

   216|## 八、起点中文网武侠投稿适配原则
   217|
   218|### 1. 先给压力，再给手段
   219|- 读者先看到人物处境被压住
   220|- 很快再看到主角的判断、手段或锋芒
   221|- 不能长期只有压抑，没有反馈
   222|
   223|### 2. 每章必须有一个可感知推进
   224|四选一至少满足一项：
   225|- 主角拿到主动权
   226|- 敌我认知发生偏转
   227|- 身份/旧案逼近一步
   228|- 关系温度或敌意明显变化
   229|
   230|### 3. 克制不等于慢
   231|- 可以冷，但前500-800字必须给冲突
   232|- 可以留白，但不能只留氛围不落结果
   233|
   234|### 4. 武侠必须持续可见
   235|每章至少出现一项：
   236|- 兵器判断
   237|- 身法/拆招
   238|- 江湖规矩
   239|- 门派旧怨
   240|- 名号压力
   241|
   242|### 5. 主角不能长期只做“病王爷”
   243|必须周期性兑现：
   244|- 判断比别人准
   245|- 出手比别人狠
   246|- 代价比别人重
   247|- 布局比别人深
   248|
   249|### 6. 章节字数底线
- 《沸腾之雪》正文章节（不含序幕）默认不少于 2000 字
- 低于 2000 字，只能视为未完成稿或过渡稿，不能当正式连载章
- 当前推荐单章区间：2200-3200 字

### 平台向禁止项
   250|- 禁止连续两章都只做铺垫
   251|- 禁止主角连续多章只被动接令
   252|- 禁止把冷感写成情绪封死
   253|- 禁止一章只有局势，没有选择
