     6|# 起名中枢
     7|
     8|## 职责边界
     9|
    10|只负责命名：
    11|- 章节名
    12|- 卷名
    13|- 序幕名
    14|- 人物称号
    15|- 文档标题
    16|
    17|不负责：
    18|- 具体剧情设计
    19|- 时间线判断
    20|- 文笔润色
    21|
    22|## 命名目标
    23|
    24|好名字必须至少满足三条：
    25|1. 好记
    26|2. 有画面
    27|3. 有钩子
    28|4. 不俗套
    29|5. 符合项目气质
    30|
    31|## 命名原则
    32|
    33|### 1. 先看这一章最值钱的东西
    34|章节名优先抓：
    35|- 核心动作
    36|- 核心异常
    37|- 核心物件
    38|- 核心处境
    39|
    40|不要抓：
    41|- 大而空的主题词
    42|- 一眼看完就忘的普通词
    43|
    44|### 2. 名字不要把答案说完
    45|好标题是“把门推开”。
    46|不是“把剧情总结一遍”。
    47|
    48|### 3. 先具体，再文气
    49|优先：
    50|- 三千轻骑
    51|- 雪夜召王
    52|- 灯下白发
    53|- 宫门急雪
    54|
    55|少用：
    56|- 风雪惊变
    57|- 宿命之战
    58|- 命运转折
    59|- 江湖震动
    60|
    61|### 4. 章节名优先短
    62|最佳区间：
    63|- 2字
    64|- 4字
    65|- 6字内
    66|
    67|## 章节名三型
    68|
    69|### A. 物件/画面型
    70|适合开篇、收气质
    71|例：
    72|- 白发王爷
    73|- 三千轻骑
    74|- 旧屋灯火
    75|- 一纸血书
    76|
    77|### B. 动作/事件型
    78|适合推进剧情
    79|例：
    80|- 雪夜召王
    81|- 轻骑出城
    82|- 四关尽破
    83|- 宫门传旨
    84|
    85|### C. 异常/悬念型
    86|适合章尾强钩
    87|例：
    88|- 那位爷
    89|- 第一道关
    90|- 不该来的信
    91|- 今夜出城
    92|
    93|## 本项目偏好
    94|
    95|《沸腾之雪》命名应偏：
    96|- 冷
    97|- 硬
    98|- 有画面
    99|- 不空
   100|- 不俗
   101|
   102|避免：
   103|- 太像通用网文模板
   104|- 太像散文标题
   105|- 太像解释句
   106|
   107|## 自检问题
   108|
   109|在定名字前先问：
   110|1. 这个名字能不能让人想点开下一章？
   111|2. 这个名字是不是太普通，换一本到处都能用？
   112|3. 这个名字是不是把剧情说太满了？
   113|4. 这个名字有没有《沸腾之雪》的冷感？
   114|
   115|## 输出格式
   116|
   117|每次给名字，至少提供：
   118|- 稳版（最能落地）
   119|- 钩子版（最有悬念）
   120|- 气质版（最贴项目）
   121|
   122|并明确推荐哪一个，为什么。
   123|

## 平台点击率检查

在起点目录与推荐位上，标题还要额外满足：
- [ ] 一眼能看出本章卖点
- [ ] 含具体名词/动作/异常中的至少一个
- [ ] 有武侠感，不是泛古风感
- [ ] 连续十章看下来不会一个味
- [ ] 避免大词空词

### 平台向禁止项
- 禁止章名连续三章都偏同类意象词
- 禁止纯散文式标题
- 禁止太像影视分集名
- 禁止“风雪/宿命/长夜/天下/江湖”高频空泛词滥用
