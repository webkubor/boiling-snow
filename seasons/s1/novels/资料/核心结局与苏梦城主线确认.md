# 核心结局与苏梦城主线确认

来源：用户直接确认
状态：高优先级设定
用途：作为第一部/整体长篇架构设计时的核心约束，后续人物关系、时间线推进、章节铺垫都要服务于此

## 一、整体大结局方向

这部小说的大结局，是天榜三绝的绝战。

核心三人：
- 苏梦城
- 慕北歌
- 欧阳狂徒

说明：
- 三绝之战是整部小说的顶层收束点
- 所有前史、误解、血债、王权、江湖局势，最终都要推向这场终局对撞
- 后续架构整理时，要把人物成长线、信息差、恩怨线、势力博弈，统一收束到“三绝绝战”这个终点

## 二、苏梦城主线确认

苏梦城关键主线：

父死
→ 从军
→ 战功赫赫封王
→ 自愿自废武功表忠心
→ 母亲被宫里人下毒手
→ 一夜白头
→ 黑市多了一个夜惊鸿

## 三、后续整理原则

1. 苏梦城的所有人物档案、回忆线、王府线，都以这条主线为准
2. 乾明十七年前后，夜惊鸿与苏梦城本质仍是同一人；但这个阶段天下并不知道，寒江淮也只是重新启用异姓王苏梦城，并未识破夜惊鸿身份
3. 三绝终局要提前埋：
   - 苏梦城：父仇、王权、隐忍、双身份
   - 慕北歌：孤山、夕歌、师门旧债、信息残缺
   - 欧阳狂徒：战场、夕歌、宿敌、破坏性意志
4. 第一部到后续各部的推进，要让三人的冲突不断升级，但不能过早打空终局价值

## 四、待后续继续补的点
- 三绝绝战发生前，各自最后的心理状态
- 三绝绝战的直接导火索
- 三绝绝战时三人各自知道了哪些真相
- 三绝绝战最终是纯胜负、共毁、还是带更高层真相揭露
