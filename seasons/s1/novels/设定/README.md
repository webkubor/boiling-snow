# 设定目录说明

这里统一收口《沸腾之雪》的核心设定，不再把世界观、兵器、榜单、地图思路散落在根目录。

## 当前文件

- `卷宗规划.md`：全书分卷逻辑、核心意象、各阶段剧情起承转合
- `世界观总纲.md`：最高层世界规则、三方格局、天榜总口径
- `武学总纲.md`：本书判断强弱、写战斗、区分高手类型的统一标准
- `内力机制.md`：解释内力如何作用于护体、运劲、持久与化力
- `兵器设定.md`：主要神兵与武器物理逻辑
- `天榜排行.md`：给正文、宣传、协作统一引用的天榜名单
- `天榜机制.md`：解释为什么天榜是战力榜，而不是内力榜
- `天门关前四道险.md`：夜惊鸿成名的核心战绩、四道死关口径与第6章起的破关约束
- `正文语气约束.md`：正文允许接地气、幽默和黑色玩笑，但不得破坏主线张力与人物层级
- `旁白口径.md`：对外文案与旁白写法参考

## 后续约定

- 地图资料统一放进 `设定/地图/`
- 视觉参考不再单独作为 JSON 长期保留，能吸收的都吸收到人物小传或兵器设定
- 设定冲突时，以 `世界观总纲.md` 为最高口径

## 地图文件

- `地图/总图.md`：三方总方位、天门关位置、关隘链与通行逻辑
- `地图/南楚.md`：丹阳城、王府、边线与南楚内外层结构
- `地图/西燕.md`：烈阳城与四道死关
- `地图/北荒.md`：孤山与北荒地势逻辑

## 使用顺序

1. 先看 `世界观总纲.md`
2. 再看 `地图/总图.md`
3. 再看 `兵器设定.md` 与 `天榜排行.md`
4. 需要人物细节时，回到根目录的 `人物小传/` 与 `人物原始口述/`
