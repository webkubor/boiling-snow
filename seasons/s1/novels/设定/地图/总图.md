# 沸腾之雪·地图总图

用途：统一《沸腾之雪》的地理方位、通行方向与战略关系。正文写行军、追杀、入关、回京时，先以本图为准。

## 一、总体方位

采用“三角夹一关”的大格局：

- **南楚**：居东南，皇权最重，城池最密，水路最发达
- **西燕**：居西，荒漠、戈壁、烈日与风沙并存，兵锋最烈
- **北荒**：居北，雪原、绝壁、山岭相连，孤山居高临下
- **天门关**：位于三方之间的咽喉地带，是三方力量最终都会撞上的中立险关

可按下列示意理解：

```text
                北荒
          （孤山 / 雪原）
                 |
                 |
西燕 —— 多道死关 —— 天门关 —— 北境边线 —— 南楚
（烈阳城）                              （丹阳城）
```

## 二、关键地理逻辑

### 1. 南楚不贴最北，但最像“中枢”
- 南楚不是纯边荒国家，而是拥有完整朝堂、皇城和大后方的中枢王朝
- **丹阳城**在南楚腹地，不在边关，但也不能离北境太远，否则苏梦城这条边军/王府线失去支撑
- 从丹阳到北境，应该是“能调兵，但来不及瞬息救火”的距离

### 2. 西燕到南楚之间，不是平推，而是层层关隘
- 欧阳狂徒要真正压到南楚核心地带，中间必须经过多道要冲
- 当前已确认可用的关隘链：
  - 落月关
  - 寒衣关
  - 碎玉关
  - 绝影关
- 这四关可统一理解为：**西燕东进、逼近南楚边线前的死亡通道**

### 3. 北荒不是“城池国家”，更像“地势与名望撑起来的江湖地带”
- 北荒的核心不是皇城，而是**孤山**
- 孤山既是地理高点，也是精神制高点
- 慕北歌下山，本质是从“与世隔绝的绝高之地”进入“已经烂透的人间秩序”

### 4. 天门关是最后总结算之地
- 不是谁都能随便来去的普通边关
- 它是三方都能勉强够到、又都不敢彻底吞下的险地
- 后期三绝绝战，放在这里最顺

## 三、当前必须记住的路线关系

### 苏梦城线
- 常驻：丹阳城 / 王府 / 皇城体系
- 向北：北境军线、边关、天门关方向
- 向西北：接西燕来路与欧阳狂徒战线

### 欧阳狂徒线
- 起点：烈阳城 / 西燕腹地
- 东进：需过四道死关
- 进入南楚视野：先到边线，再到更深处，不可能无声无息直抵丹阳

### 慕北歌线
- 起点：北荒孤山
- 南下/西南下：先出孤山，再入三方混乱地带
- 他进入天门关方向，比进入丹阳更自然
