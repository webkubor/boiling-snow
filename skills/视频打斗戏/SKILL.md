# 视频打斗戏 Skill

**版本**: v2.0  
**来源**: 《沸腾之雪》打斗戏生产体系  
**用途**: 15秒武侠/高武打斗视频脚本生成

---

## 零、大师思维框架

> 本章是视频脚本的底层逻辑。读懂这一章，就能自己诊断问题、适应新场景、创造新打法。不只是执行规则，是理解规则为什么存在。

---

### 0.1 视频是时间的艺术，不是文字的艺术

脚本写的是**时间分配**，不是文学描述。你写的每一个动作段，本质上是在分配观众的**注意力资源**。

15秒 = 15000ms。观众在同一时刻只能集中注意力在一个焦点上。

核心问题：你想让观众**什么时候看什么**？

| 时段 | 观众在做什么 | 脚本的任务 |
|------|------------|----------|
| 0-2s | 定位 | 谁？在哪？什么情绪？冲突在哪？ |
| 2-13s | 跟随 | 攻防交换、力量碰撞、空间争夺 |
| 13-15s | 接收 | 结果是什么？用什么方式赢/输？ |

**所以打斗戏的核心不是"写招式"，是"管理观众的注意力往哪集中"。**

---

### 0.2 打斗的本质：物理冲突的视觉化

两个高手交锋，本质上在做四件事：

1. **位移**：谁在空间上取得优势（抢中线、绕后、占据高点）
2. **破防**：谁先找到对方的空档（物理接触的瞬间）
3. **力量传递**：击中之后力往哪走（透过身体 → 推到环境）
4. **状态变化**：这次交锋之后，双方的位置和状态有什么改变

高手打斗不是"你一招我一招"，而是**空间控制权的持续争夺**。

---

### 0.3 镜头是视角的选择，不是好看的画面

每一种镜头语言背后都有一个信息目的。选镜头时问自己：我想让观众感受到什么？

| 运镜 | 传递的信息 |
|------|-----------|
| 低机位仰拍 | 对方很强大 / 正在上升 / 有压迫感 |
| 高机位俯拍 | 我在掌控全局 / 对方被压制 |
| 贴身短焦 | 细节、紧张、武器距离内的真实感 |
| 跟踪拍摄 | 位移、速度感、空间变化 |
| 史诗大远景 | 这一刻很重要，需要展示规模和格局 |

镜头是**信息工具**，不是装饰品。

---

### 0.4 动作密度控制：注意力带宽管理

AI 生成视频糊了，90%是因为动作密度超载。

底层逻辑：AI 处理每个像素时，注意力是有限的。在 3 秒内塞 6 个动作，AI 的注意力被分散 → 每个动作都处理不完整 → 全糊。

大师做法：**主动降低密度，让每个动作都被完整处理。**

每段 1-2 个核心动作 = AI 把所有算力集中在这 1-2 个动作上 = 每个动作清晰有力。

**少即是多，不是美学选择，是技术约束。**

---

### 0.5 物理来源：因果链的建立

"他飞到树上" → AI 不理解，因为没有因果链。

AI 生成视频时需要像素层面的物理逻辑：

```
起点 → 力的来源 → 力的传递 → 终点
```

没有因果链，AI 就会自由发挥 → 生成离谱画面。

检查每一个位移动作：有没有说明**起点、力的来源、力的传递、终点**？有没有断链的地方？

---

### 0.6 轻功的逻辑：寻找地面替代物

普通人走路，脚下始终有支撑（地面）。轻功的本质是：**失去地面支撑 → 寻找替代支撑物。**

"贴地滑行" → AI 理解为：脚还在地面 → 人在爬。

"蹬墙奔跑" → AI 理解为：人在墙上跑，没有腾空。

**轻功的核心关键词：离地多少厘米、离地多久、靠什么借力。**

动作链 = 脚点某物借力 → 身体离地 → 空中移动 → 落点产生物理反馈。

---

### 0.7 间接杀人：力量外溢的美学

直接砍中 → 画面脏、暴力感强、格局小。  
天榜高手的方式 → 内力/气劲/动能传递 → 杀人于无形。

底层逻辑：**真正的高手不直接碰你，他的力量透过你传递到环境。**

这不是玄幻设定，是视觉美学：干净、克制、更高级、更强大。杀人之后对方"才"倒下，比当场血流满地更有压迫感。

---

### 0.8 收尾的逻辑：不要浪费观众的期待

15 秒片的最后一秒，观众的情绪已经被打到高点。

❌ 缓缓走远 → 情绪泄掉，破坏整体节奏  
❌ 雪风吹得猎猎作响 → 情绪被打断，留白太多

收尾只有两件事：
1. **结果定格**：谁赢了？用什么方式赢的？
2. **一个动作结束**：不用解释，视觉直接传达。

省下来的时间给激战。

---

### 0.9 大师写脚本时的思维链

拿到一个打斗需求时，大师想的是：

```
1. 这场戏要传达的核心信息是什么？
   （空间控制权争夺？力量悬殊展示？角色性格揭示？）

2. 观众的情绪曲线应该怎么走？
   （压抑→爆发？试探→确认？绝望→放弃？）

3. 每个时间段的注意力焦点在哪？
   （0-2s定位 / 2-13s跟随 / 13-15s结果）

4. 每个动作段的核心冲突是什么？
   （谁占上风？怎么体现？用什么镜头强化？）

5. 因果链完整吗？
   （起点→力源→传递→终点，有没有断链？）

6. 密度合适吗？
   （每段1-2个动作，观众能跟上吗？）

7. 收尾干净吗？
   （情绪有没有被破坏？）
```

## 一、硬红线（零容忍，违反=废片）

1. **禁止文学修辞** — 所有动作必须用物理量描述（身体部位+方向+力度+接触点+位移）
2. **禁止站桩** — 全程必须有位移，禁止两人面对面站定后出招
3. **禁止回合制** — 连续攻防流，双方同时移动同时出手，不是"A出一招→B接一招→A再出"
4. **武器全程锁死** — 长度/材质/主从关系不变，不断裂不变形不脱手不互换
5. **禁止慢镜头摆拍** — 慢镜头只用于：武器接触皮肤瞬间 / 刀锋擦过血线 / 剑尖点破衣甲
6. **禁止主动攻击环境** — 高手打的是人，环境是余波。不能写"挥剑劈断竹竿""踢飞灯笼"

## 二、时间分配（15秒 = 15000ms）

| 时段 | 时长 | 做什么 | 禁止 |
|------|------|--------|------|
| 起势 | 0-2s | 首次接触，交代环境 | 空拍摆pose，超过2s |
| 激战 | 2-13s | 全部精华，每2秒至少1次攻防交换 | 超过1s无攻防交换 |
| 收尾 | 13-15s | 定格/对视，≤1秒结束 | 文艺收尾、缓慢走远 |

**激战期单招时长**: 0.3-0.6秒，禁止演示感慢动作。

## 三、轻功规则

### 核心原则：必须写"离地"

❌ 错误写法 → AI理解结果：
- "贴地滑行" → 蛤蟆趴在地上往前爬
- "蹬墙奔跑" → 普通跑墙，没有腾空
- "滑步/垫步/切步" → 普通走路变体
- "身体悬停" → 原地飘浮

✅ 正确写法：身体凌空离地N厘米沿某方向平移N米，双脚全程不触地面，落地时脚点某物产生物理反馈。

### 动作链模板
```
脚点X物借力 → 身体离地Y厘米沿Z方向平移N米 → 落地时脚点Y物产生物理反馈
```

### 借力点速查
| 地形 | 借力点 |
|------|--------|
| 雪竹林 | 竹竿（竹竿弯曲蓄力） |
| 王府飞檐 | 瓦片/屋脊/廊柱 |
| 雨巷 | 墙壁/屋檐 |
| 雪原枯林 | 枯树/冰面/岩石 |
| 古栈道 | 木板/栏杆/柱子 |

### 运镜配合
- 优先长镜头跟随 + 背景动态模糊
- 禁止复杂运镜（环绕360°/急甩）拍轻功，会暴露肢体瑕疵

## 四、动作尺度与力量感

### 天榜级高手标准

- **位移尺度**：每次交锋位移至少5-10米，不是1-2米的小碎步
- **环境破坏**：不是踩裂一块地，是一整片区域被气浪夷平
- **交锋距离**：两人交锋时有明显冲撞和分离，不是贴在一起缠斗
- **力量外溢**：每招余波必须影响周围环境

### 力度反馈三要素（每次击中必须写）

1. **碰撞瞬间的视觉效果**：气雾/火花/冲击波/裂纹/血珠震飞
2. **受击者的物理位移**：被推多远、撞到什么、环境怎么坏
3. **双方都有物理反应**：谁都没站稳、双方都滑退

❌ "一掌拍开指法"  
✅ "掌心气浪与指力碰撞爆开白色气雾，两人同时向后滑退数米靴底在地面犁出深痕"

### 密度控制
每段（2-3秒）只写1-2个核心动作。宁可少而精，不要多而烂。

### 位移必须写
每个动作附带：从哪到哪、横移几米、向前推进几米。

❌ "她向前冲" → ✅ "她从巷口凌空平移到巷尾7米处"

## 五、镜头美学规则

### 5.1 运镜选择（每段只选一种）

| 场景 | 运镜 | 原因 |
|------|------|------|
| 对穿抢位 | 中景侧跟 | 看双方位移和距离 |
| 轻功腾空 | 低机位仰拍 | 突出高度和速度 |
| 近身破招 | 贴身短焦 | 武器距离内打击细节 |
| 群战调度 | 高机位俯拍 | 看清多人站位和阵型 |
| 史诗高潮 | 大远景俯拍 | 宏大尺度，7-10s区间用一次 |
| 收尾定格 | 缓拉中景 | 自然收束 |

### 5.2 切镜频率
- 15秒片 3-5次切镜，不超过7次
- 每次切镜必须有信息增量（新角度/新动作/新环境反馈）
- 同一段内（2-3秒）保持同一运镜

### 5.3 史诗镜头配额
- 全片最多1次，1-2秒，必须在7-10s区间
- 必须包含人物+战斗痕迹，禁止纯环境空镜
- 禁止用于起势和收尾

### 5.4 特写规则

| 类型 | 配额 | 位置 |
|------|------|------|
| 战斗特写 | ≥60% | 打斗中间（武器接触瞬间） |
| 环境特写 | 由动作触发 | 必须写触发原因 |
| 表情特写 | ≤1次，≤0.3s | 打斗中间 |
| 慢镜头 | ≤1次，0.2-0.35s | 打斗中间（关键打击瞬间） |

慢镜头只用于：武器接触皮肤瞬间、刀锋擦过血线、剑尖点破衣甲、拳骨撞击关节。慢镜头后必须极速回正（0.1s内恢复实时速度）。

## 六、武器规则

1. **全程锁死**：长度/材质/主从关系不变，不断裂不变形不脱手不互换
2. **脱手必须符合物理**：重力+抛物线+旋转衰减
   - ❌ "刀旋转飞出劈断灯笼"（武器脱手做花哨的事）
   - ✅ "刀脱手落地" / "刀飞出数米钉入地面"
3. **弓手/弩手**：必须写弹道（从哪射出→经过什么→钉在哪），近距离禁止"完整拉弓实射"

---

## 七、敌人调度

- **站位必须写**：几个敌人、从哪个方向、用什么招
- **禁止回合制**：高手打菜鸟是"一招带一片"，不是逐个击破
- 多人同时压迫 → 主角用走位/环境/轻功破阵 → 敌人互相挡路/误伤/阵型崩溃

---

## 八、物理来源铁律

任何人不能凭空移动/飞到树上/瞬移。每个位移动作必须有明确物理来源：

| 物理来源 | 示例 |
|---------|------|
| 重力势能 | 从飞檐坠落 → 转化为水平动能 |
| 接触点反作用力 | 蹬墙/蹬柱/蹬人借力后空翻 |
| 弹性蓄力 | 脚尖点弯曲竹竿 → 弹射 |
| 惯性 | 高速滑步 / 蹬转变向 |

---

## 九、间接杀人原则

天榜高手杀人不是"砍一刀流一地血"，是**间接伤害**：

| 角色 | 杀人方式 |
|------|---------|
| 慕北歌 | 横向一抹→三人咽喉红线并封冻（剑气余波） |
| 苏梦城 | 刺客直到此刻才缓缓倒地（枪劲渗透延迟生效） |
| 欧阳狂徒 | 重甲碎裂+血液震成红雾（动能传递） |
| 萧烬弦 | 寂灭指扣喉→迸发暗劲震退数米（指力穿透） |

## 十、交付格式

```
场景：[地形+尺度+光照+天气]。人物：[@角色图 角色名 武器 物理特性]。敌方：[数量+武器+站位]。

时间段1｜段名 [运镜]。[动作描述，包含位移起点终点]。  
时间段2｜段名 [运镜]。[动作描述]。  
...  
最后一段｜段名 [运镜]。[动作描述，≤1秒]。
```

**规则**：
- 纯文本，不分段不换行
- 无卡点标注，无对白（对白留给配音）
- 环境反馈融入动作描述，不单独写
- 每段只写1种运镜，不堆砌

## 十三、可复用母版

### E1 双人极速对抗（无第三人）
场景：{同一空间，不换场}。人物：{A}与{B}双人对抗，禁止第三人下场。
视频要求：15秒，24fps，16:9，35mm胶片颗粒，电影级低调摄影，真实体积光与环境反射，无字幕无字卡无水印无Logo，无现代元素。
动作：
- 0-2s 高速对穿抢中线，首次接触即交锋
- 2-5s 远距封线与步点扰动，连续攻防交换
- 5-8s 近身三连破招，慢放0.3s打在第2招接触瞬间
- 8-11s 核心破局（内劲对冲或擒拿反制）
- 11-13s 半招压制
- 13-15s 收势定格
音频：无BGM无对白，仅场景音与兵器拟音。

### E2 一对多（群战）
人物：{A} vs {N名敌人}。敌人必须标注数量、站位、武器、出场顺序。禁止回合制。主角用走位/环境破阵。弓手/弩手必须有弹道描写。镜头：中景跟主角为主，1次高机位俯拍展示敌阵。音频：同E1。

### E3 空中对穿（轻功强化）
场景：{同一空间含可借力点：柱/栏/梁}。人物：{A}/{B}。镜头：低机位仰拍为主，1次中景侧跟。
动作：0-2s同步蹬地起跳并首次交错 → 2-5s空中远程互压 → 5-8s二次腾空变线 → 8-11s落地贴身反制 → 11-13s双人对峙 → 13-15s收尾。每次起落都要有落点反馈，禁止漂浮。

## 十五、Seedance 2.0 平台规则

> 以下规则来自 Seedance 2.0 官方结构化提示词系统。

### 15.1 Prompt 必须按 S-A-C-S 结构

```
S（Subject 主体）：@图片1 角色参考，@图片2 场景参考
A（Action 动作）：每段一个核心动作，现在时态动词
C（Camera 镜头）：景别 + 运动 + 角度 + 镜头
S（Style 风格）：视觉锚点 + 光照 + 色调
约束：[负面约束词]
```

### 15.2 @图片引用规则
- 上传角色图 → `@图片1` 引用，不要写外貌描述
- 上传场景图 → `@图片2` 引用，不要写文字描述场景
- **@引用 = AI严格跟随参考，文字描述 = AI自由发挥**

### 15.3 镜头术语速查

| 英文 | 中文 | 用途 |
|------|------|------|
| wide shot (WS) | 大远景 | 史诗感 |
| crane shot | 升降镜头 | 宏大场面 |
| tracking shot | 跟拍 | 跟随位移 |
| low angle | 低机位 | 仰拍力量感 |
| high angle | 高机位 | 俯拍全貌 |
| handheld | 手持 | 真实感/绝望感 |
| dolly in/out | 推拉 | 聚焦/退远 |
| slow motion | 慢动作 | 关键瞬间 |
| snap zoom | 急推 | 禁止（摆拍感） |

### 15.4 负面约束（每次必追加）

```
约束：no extra characters, no crowd, no extra fingers, no extra limbs, no distortion, no deformed hands, no warped faces, no melting edges, no jump cuts, no lens flares, no text overlays, no watermarks, no blurry motion, no snap zooms, no whip pans, no oversaturated colors.
```

### 15.5 5秒分段迭代

复杂打斗不要一次生成15秒。先5秒×3个变体 → 挑最好的 → 逐段延长。

## 十六、流程步骤（每次写脚本前走一遍）

### STEP 0：前置准备

1. 读§零大师思维框架（必读）
2. 确认：场景 + 人物 + 武器 + 敌方数量/站位 + 时长 + 情绪

### STEP 1：按时间分配写骨架

- 0-2s 起势：环境 + 就位 + 首次接触（非摆pose）
- 2-13s 激战：连续攻防，分配视觉资源（慢镜头/史诗镜头/特写配额）
- 13-15s 收尾：≤1秒

### STEP 2：逐段写动作（用§零思维链检查）

每段（2-3秒）：
1. 这段要传达的核心信息是什么？（空间争夺/力量碰撞/角色揭示）
2. 选运镜（一种）
3. 写1-2个核心动作（物理量描述）
4. 每个动作带位移（从哪到哪 + 几米）+ 物理来源
5. 融入环境反馈（是余波，不是主动攻击）
6. 涉及轻功必须写离地

### STEP 3：检查敌人调度

- 所有敌人有站位和动作？
- 不是回合制？
- 弓手有弹道？

### STEP 4：转交付格式

- 纯文本不分段不换行
- 无卡点标注、无对白
