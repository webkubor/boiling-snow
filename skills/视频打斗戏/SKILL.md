# 视频打斗戏 Skill

**版本**: v1.0  
**来源**: 《沸腾之雪》打斗戏生产体系  
**用途**: 15秒武侠/高武打斗视频脚本生成，规则覆盖全类型兵器、轻功、群战

---

## 核心原则

打斗戏靠**规则体系**输出质量，不靠灵感或随性发挥。  
拿到角色信息后，严格按本 Skill 输出脚本，不得自由发挥。

---

## 一、硬红线（零容忍）

1. 禁止文学修辞 — 所有动作必须用**物理量描述**（身体部位+方向+力度+接触点+位移）
2. 禁止站桩 — 全程必须有位移，禁止两人面对面站定后出招
3. 禁止回合制 — 连续攻防流，双方同时移动同时出手
4. 武器全程锁死 — 长度/材质/主从关系不变，不断裂不变形不脱手不互换
5. 禁止慢镜头摆拍 — 慢镜头只用于：武器接触皮肤瞬间 / 刀锋擦过血线 / 剑尖点破衣甲

---

## 二、时间分配（15秒 = 15000ms）

| 时段 | 时长 | 做什么 | 禁止 |
|------|------|--------|------|
| 起势 | 0-2s | 首次接触，交代环境 | 空拍摆pose，超过2s |
| 激战 | 2-13s | 全部精华，每2秒至少1次攻防交换 | 超过1s无攻防交换 |
| 收尾 | 13-15s | 定格/对视，≤1秒结束 | 文艺收尾、缓慢走远 |

**激战期单招时长**: 0.3-0.6秒，禁止演示感慢动作。

---

## 三、镜头美学规则

### 3.1 运镜选择（每段只选一种）

| 场景 | 运镜 | 原因 |
|------|------|------|
| 对穿抢位 | 中景侧跟 | 看双方位移和距离 |
| 轻功腾空 | 低机位仰拍 | 突出高度和速度 |
| 近身破招 | 贴身短焦 | 武器距离内打击细节 |
| 群战调度 | 高机位俯拍 | 看清多人站位和阵型 |
| 史诗高潮 | 大远景俯拍 | 宏大尺度，7-10s区间用一次 |
| 收尾定格 | 缓拉中景 | 自然收束 |

### 3.2 切镜频率
- 15秒片 3-5次切镜，不超过7次
- 每次切镜必须有信息增量
- 同一段内（2-3秒）保持同一运镜

### 3.3 史诗镜头配额
- 全片最多1次，1-2秒，必须在7-10s区间
- 必须包含人物+战斗痕迹，禁止纯环境空镜
- 禁止用于起势和收尾

### 3.4 特写规则

| 类型 | 配额 | 位置 |
|------|------|------|
| 战斗特写 | ≥60% | 打斗中间（武器接触瞬间） |
| 环境特写 | 由动作触发 | 必须写触发原因 |
| 表情特写 | ≤1次，≤0.3s | 打斗中间 |
| 慢镜头 | ≤1次，0.2-0.35s | 打斗中间（关键打击瞬间） |

---

## 四、轻功规则

### 核心：必须写"离地"

❌ 错误 → AI理解结果：
- "贴地滑行" → 蛤蟆趴在地上往前爬
- "蹬墙奔跑" → 普通跑墙，没有腾空
- "滑步/垫步/切步" → 普通走路变体

✅ 正确写法：
- 身体凌空离地30cm向前高速平移
- 双脚全程不触地面
- 身体水平悬停/足尖不触地

### 动作链模板
```
脚点X物借力 → 身体离地Y厘米沿Z方向平移N米 → 落地时脚点Y物产生物理反馈
```

### 运镜配合
- 优先长镜头跟随 + 背景动态模糊
- 禁止复杂运镜（环绕360°/急甩）拍轻功，会暴露肢体瑕疵

---

## 五、动作尺度与力量感

### 天榜级高手标准

- **位移尺度**：每次交锋位移至少5-10米
- **环境破坏**：一整片区域被气浪夷平（树木连片折断、地面犁出十几米沟痕）
- **交锋距离**：两人交锋时有明显冲撞和分离，不是贴在一起缠斗
- **力量外溢**：每招余波必须影响周围环境（风压刮倒远处的人、气浪震碎远处的东西）

### 密度控制
- **每段（2-3秒）只写1-2个核心动作** — 多了AI平均分配注意力，全糊
- 宁可少而精，不要多而烂

### 位移必须写
每个动作附带：从哪到哪、横移几米、向前推进几米

❌ "她向前冲" → ✅ "她从巷口凌空平移到巷尾7米处"

---

## 六、武器规则

1. **全程锁死**：长度/材质/不断裂/不变形/不脱手/不互换
2. **脱手必须符合物理**：重力+抛物线+旋转衰减，不写花哨事
3. **弓手/弩手**：必须写弹道（从哪射出→经过什么→钉在哪），近距离禁止"完整拉弓实射"

---

## 七、敌人调度

- **站位必须写**：几个敌人、从哪个方向、用什么招
- **禁止回合制**：高手打菜鸟是"一招带一片"，不是逐个击破
- 多人同时压迫→主角破阵→敌人互相挡路/阵型崩溃

---

## 八、物理来源铁律

任何人不能凭空移动/飞到树上/瞬移。每个位移动作必须有明确物理来源：

| 物理来源 | 示例 |
|---------|------|
| 重力势能 | 从高处坠落→转化为水平动能 |
| 接触点反作用力 | 蹬墙/蹬柱/蹬人借力后空翻 |
| 弹性蓄力 | 脚尖点弯曲竹竿→弹射 |
| 惯性 | 高速滑步/蹬转变向 |

---

## 九、间接杀人原则

天榜高手杀人不是"砍一刀流一地血"，是**间接伤害**：

| 角色 | 杀人方式 |
|------|---------|
| 慕北歌 | 横向一抹→三人咽喉红线并封冻（剑气余波） |
| 苏梦城 | 刺客直到此刻才缓缓倒地（枪劲渗透延迟生效） |
| 欧阳狂徒 | 重甲碎裂+血液震成红雾（动能传递） |
| 萧烬弦 | 寂灭指扣喉→迸发暗劲震退数米（指力穿透） |

---

## 十、交付格式

```
场景：[地形+尺度+光照+天气]。人物：[@角色图 角色名 武器 物理特性]。敌方：[数量+武器+站位]。

时间段1｜段名 [运镜]。[动作描述，包含位移起点终点]。  
时间段2｜段名 [运镜]。[动作描述]。  
...  
最后一段｜段名 [运镜]。[动作描述，≤1秒]。
```

**规则**：
- 纯文本，不分段不换行
- 无卡点标注，无对白（对白留给配音）
- 环境反馈融入动作描述，不单独写
- 每段只写1种运镜，不堆砌

## 十三、可复用母版

### E1 双人极速对抗（无第三人）
场景：{同一空间，不换场}。人物：{A}与{B}双人对抗，禁止第三人下场。
视频要求：15秒，24fps，16:9，35mm胶片颗粒，电影级低调摄影，真实体积光与环境反射，无字幕无字卡无水印无Logo，无现代元素。
动作：
- 0-2s 高速对穿抢中线，首次接触即交锋
- 2-5s 远距封线与步点扰动，连续攻防交换
- 5-8s 近身三连破招，慢放0.3s打在第2招接触瞬间
- 8-11s 核心破局（内劲对冲或擒拿反制）
- 11-13s 半招压制
- 13-15s 收势定格

### E2 一对多（群战）
人物：{A} vs {N名敌人}。敌人必须标注数量、站位、武器、出场顺序。禁止回合制。主角用走位/环境破阵。弓手/弩手必须有弹道描写。镜头：中景跟主角为主，1次高机位俯拍展示敌阵。

### E3 空中对穿（轻功强化）
场景：{同一空间含可借力点：柱/栏/梁}。人物：{A}/{B}。镜头：低机位仰拍为主，1次中景侧跟。
动作：0-2s同步蹬地起跳并首次交错 → 2-5s空中远程互压 → 5-8s二次腾空变线 → 8-11s落地贴身反制 → 11-13s双人对峙 → 13-15s收尾。每次起落都要有落点反馈，禁止漂浮。

---

## 使用流程

1. 收集信息：角色 + 武器 + 敌方数量 + 场景地形 + 时长 + 情绪
2. 选母版（E1/E2/E3）或从零写
3. 按时间分配填骨架
4. 逐段写动作（运镜+动作+位移+环境反馈）
5. 自检清单逐条过
6. 交付格式输出
