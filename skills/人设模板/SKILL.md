# 人设模板 Skill

**版本**: v1.0  
**来源**: 《沸腾之雪》角色生产体系  
**用途**: 创建武侠/高武角色 JSON，结构化沉淀角色数据

---

## 核心原则

人设是 AI 生产体系的锚点。所有角色数据必须结构化存储，确保：
- AI 生成角色图时能精准锁定面部/服饰锚点
- AI 写脚本时能还原角色动作特征和武学体系
- 多人协作时数据一致、不走形

---

## JSON Schema（必填字段）

```json
{
  "姓名": "string（中文名）",
  "ID": "string（英文 kebab-case，唯一标识）",
  "天榜排名": "天榜第N (Rank NN) | null",
  "所属势力": "string（势力名 + 核心定位）",
  "性格画像": {
    "核心特质": ["特质1", "特质2"],
    "核心冲突": "string（如：温柔外表 vs 狠辣内心）",
    "心理底色": "string（内心独白/行为动机）",
    "立场": "string（与主角/其他角色的关系定位）",
    "动作特征": ["动作标签1", "动作标签2"],
    "表达风格": "string（语言风格、语气特点）"
  },
  "生平背景": {
    "出身": "string（一句话出身）",
    "前世今生": ["关键事件1", "关键事件2", "关键事件3"],
    "核心标签": ["tag1", "tag2", "tag3"]
  },
  "人物关系": [
    {
      "目标": "target-id（另一角色的ID）",
      "类型": "关系类型",
      "描述": "string"
    }
  ],
  "武学体系": {
    "总纲": "string（一句话武学核心理念）",
    "轻功身法": {
      "名称": "string",
      "描述": "string"
    },
    "近身": "string",
    "远程": "string",
    "禁止": ["禁止动作1", "禁止动作2"]
  },
  "视觉规范": {
    "面部特征": "string（眼神/气质/肤质要求）",
    "服饰": "string（总风格描述）",
    "衣橱档案": [
      {
        "名称": "string",
        "场合": "string",
        "描述": "string"
      }
    ],
    "武器": {
      "主武": "string（武器名 + 类型）",
      "特性": "string（物理特性，非玄幻）"
    }
  },
  "风格标签": ["tag1", "tag2"]
}
```

---

## 字段说明

### 姓名 + ID
- 姓名：中文全名，用于显示
- ID：英文 kebab-case，用于关系引用（如 `su-meng-cheng`）
- 曾用名/化名：可加 `曾用名` 字段

### 天榜排名
- 格式：`天榜第N (Rank NN)`
- 无排名角色填 `null`，但需要在 `风格标签` 中标注定位

### 性格画像

| 字段 | 用途 |
|------|------|
| 核心特质 | 3-5个关键词，定义角色行为模式 |
| 核心冲突 | 最重要的内心矛盾，是角色多面的根源 |
| 心理底色 | 用一句话描述角色内心深处的驱动力 |
| 立场 | 与核心人物的关系定位（效忠/对立/暧昧等） |
| 动作特征 | AI写动作时的参考标签（如"大开大合""极速身法"） |
| 表达风格 | 语气/措辞特点（冷峻/话少/信息密度高等） |

### 生平背景

| 字段 | 用途 |
|------|------|
| 出身 | 一句话，说明角色从哪来 |
| 前世今生 | 3-5个关键事件的时间线，按发生顺序排列 |
| 核心标签 | 检索用标签池 |

### 人物关系

格式：`目标（ID）+ 类型 + 描述`  
关系类型参考：
- 效忠/报恩
- 对立/宿敌
- 至交/闺蜜
- 温情/暧昧
- 师徒/传承
- 试探/博弈

### 武学体系

| 字段 | 规则 |
|------|------|
| 总纲 | 一句话武学核心理念，AI生成动作的指导原则 |
| 轻功身法 | 必须写名称+描述，AI生成轻功动作时参照 |
| 近身 | 近距离战斗方式 |
| 远程 | 远程战斗方式 |
| 禁止 | 该角色**绝对不能出现**的动作（如"近距离完整拉弓实射"） |

### 视觉规范

| 字段 | 规则 |
|------|------|
| 面部特征 | 写"眼神+气质+肤质"，不要写具体五官数据（那是视觉锚点的事） |
| 服饰 | 写总风格+剪裁要求，不写具体颜色（那是衣橱档案的事） |
| 衣橱档案 | 按场合分类，每个场合3-5套，足以覆盖主要场景 |
| 武器 | 写**物理特性**而非玄幻特效（如"高频振动+点杀"而非"剑气纵横"） |

---

## 角色创建流程

1. **基本信息**：姓名、ID、天榜排名、所属势力
2. **性格画像**：核心特质→核心冲突→心理底色→立场→动作特征→表达风格
3. **生平背景**：出身→前世今生时间线→核心标签
4. **人物关系**：列出与核心角色的关系（目标+类型+描述）
5. **武学体系**：总纲→轻功→近身→远程→禁止
6. **视觉规范**：面部→服饰→衣橱档案→武器
7. **风格标签**：总结性标签池

---

## 角色类型参考

### 天榜级高手
- 必填天榜排名
- 武学体系必须包含"禁止"字段（天榜高手有明确的动作禁区）
- 视觉规范要有"巅峰决战"专用服装

### 普通角色
- 可不填天榜排名
- 武学体系可以简化
- 衣橱档案至少2套

### 女性角色
- 视觉规范中"服饰"字段必须注明是否执行【女性身段令】
- 衣橱档案按场合细分（日常/夜行/盛装/实战）

---

## 反模式

❌ 性格画像空洞（只有"勇敢善良"这种废话）  
✅ 核心冲突明确（如"又纯又欲的仙姿 vs 狠辣决绝的暗箭"）

❌ 出身模糊（"自幼习武"）  
✅ 前世今生有具体事件（因XX灭门→被XX救下→化身XX复仇→归于XX麾下）

❌ 武器写玄幻特效（"剑气纵横"）  
✅ 武器写物理特性（"高频振动+点杀"）

❌ 人物关系只有"敌人/朋友"  
✅ 关系类型细分（效忠/报恩/温情告诫/至交闺蜜等）

---

## 验收标准

- [ ] JSON 格式合法（无语法错误）
- [ ] 所有必填字段齐全
- [ ] 人物关系中的 `target` 能对应到其他角色的 `ID`
- [ ] 武学体系中的"禁止"字段能指导 AI 规避错误动作
- [ ] 视觉规范中的衣橱档案能覆盖主要场景
- [ ] 核心冲突和心理底色能解释角色的关键行为决策
