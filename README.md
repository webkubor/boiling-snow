# Cinematic Storyboard Pro (电影级分镜专家)

> **基于 AI 的写实武侠微电影分镜与提示词生产系统**

本项目是一个专门为《雪中悍刀行》风格（写实武侠/电影感）微电影设计的自动化分镜与角色管理包。通过集成角色档案、视觉规范和分镜脚本，实现从剧本到生产级 AI 视频提示词的快速转化。

## 📂 项目结构

```text
├── SKILL.md                # Gemini CLI 核心技能定义（分镜生成逻辑）
├── cast/                   # 角色档案库 (JSON)
│   ├── mu-bei-ge.json      # 白衣剑仙·慕北歌
│   ├── su-meng-cheng.json  # 南楚王爷·苏梦城
│   └── ...
├── cast_refs/              # 角色定妆参考图（面部一致性锚点）
├── references/             # 视觉与美学规范
│   ├── visual_style_guide.md   # 光影、材质与色调指南
│   └── snow_stride_aesthetic.md # 叙事美学与构图规范
├── scripts/                # 剧本分集目录
└── assets/                 # 核心资产（封面、音乐设计等）
```

## 🚀 核心功能

1.  **角色一致性锁定**：通过 `cast/*.json` 锁定角色的物理特征（如苏梦城的黑金锦袍、唐横刀），确保多镜头下角色不“穿帮”。
2.  **写实武侠渲染**：自动在生成的 Prompt 中注入体积光、电影感胶片颗粒及真实的物理材质描述。
3.  **动态叙事分镜**：生成包含 15 秒内多镜头切换（景别、运镜、动作、音效）的标准分镜表格。
4.  **AI 视频提示词优化**：专为 Sora/可灵/Runway 设计的带有时间锚点的综合提示词。

## 🛠 使用说明

在 Gemini CLI 中激活项目后，可使用以下指令：

*   **生成分镜**：`帮我为 [角色名] 生成 [动作/场景] 的分镜脚本。`
*   **同步剧本**：`根据 scripts/ep01.md 的内容拆解分镜。`
*   **角色验证**：`node scripts/validate_cast.cjs` (验证角色数据完整性)。

## 📝 开发者备注

*   **身份一致性**：必须严格依赖 `cast_refs/` 下的原始参考图进行图生图操作。
*   **美学标准**：所有输出应遵循 `references/visual_style_guide.md` 中的“物理真实”原则。
