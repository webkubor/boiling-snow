# 《沸腾之雪》最终脚本格式（唯一模板）

用途：所有 15s 可直接生成的视频命令，一律按此模板输出；不再混用零散格式。

硬性要求：
1) 总字数不超过 2000 字。
2) 不使用 Markdown 强调符号（如 **）。
3) 不写“导演口令/解释文字/注释”，只给可执行命令正文。
4) 对话段默认少切镜；若是固定对话场，必须写明站位不变与不跳轴。
5) 人体与道具一致性红线：严禁出现多手、多臂、多武器复制、武器瞬间替换或凭空增减。
6) 交付口径红线：用户明确要“剧情/梗概/分场”时，只输出剧情文本，不输出命令格式。

最终脚本模板（直接替换变量）：
场景：{地点与环境细节，保持单一连续空间或明确切换}
人物：{角色A}、{角色B}、{角色C；默认参考图锁定，不重复服装描述}
视频要求：15秒，24fps，16:9，35mm胶片颗粒，电影级低调摄影，真实体积光与环境反射，无字幕无字卡无水印无Logo，无现代元素，无符文神光，无无动机跳切。
镜头要求：{是否固定机位/是否一镜到底/允许几次特写/是否允许切镜}
剧情：0-3秒：{动作与台词}；3-6秒：{动作与台词}；6-9秒：{动作与台词}；9-12秒：{动作与台词}；12-15秒：{动作与台词与收束方式}
动作规则：每次攻击或动作都要完整呈现 起手蓄势→发力路径→命中反馈→收势；角色通过惯性连续移动，无站桩；轻功/高速位移可出现残影，但必须有可追踪物理轨迹；内力必须有触发动作与传播轨迹，不可凭空生效；武器长度与材质全程不变。
连续性约束：同一角色在同一时段仅允许一套肢体拓扑与一件主武器；若出现残影，残影仅作运动拖影，不得形成可独立攻击的“分身”。
轻功默认锁定：严禁凭空飞行或无视重力漂移；轻功本体必须在0.3-0.6秒内与环境产生可识别交互（落点水花、滑痕、衣摆回弹、切雾、火焰偏转）；动作链固定“脚点地瞬起->空中变线->落地接招”；每2秒至少一次3米以上位移；可有运动模糊残影但仅一个本体有效，残影不可独立攻击。
对抗反馈：命中以击退、倒飞、失衡、破防、环境扰动体现；避免“轻飘倒地”；高手对抗优先体现节奏压制、预判与反制，不写杂兵回合制排队挨打。
环境反馈：{积水/积雪/尘土/木梁/灯焰/门轴/栏杆}随受力变化有明确反馈（飞溅、震颤、偏转、破裂、回弹）。
音频：全程无BGM，仅场景音与拟音；{风声/脚步/布料/兵器/木结构/人群低鸣/呼吸}；台词语速自然，不为压 15 秒强塞对白。
结尾：{定格同框 或 留白悬停 或 镜头停驻}，不强制收黑。

对话场景专用补丁（需要时追加到“镜头要求”后）：
全程固定在{同一空间}，{关键道具/屏风/石台/门位}位置不变。{角色A}始终在{位置A}，{角色B}始终在{位置B}，站位不变。对话场景不频繁切镜，以主机位中景为主，仅允许{N}次短特写（手部/眼神），不得跳轴。

高速武打专用补丁（需要时追加到“动作规则”后）：
前2秒强制高速运动与强运动模糊，后续保持高机动。允许“瞬移感”表现为超高速位移残影，不是魔法闪现；必须可见起步、变线、到位三段轨迹。多人对抗时，敌方反应要有层次：先判断失误，再阵型破裂，再恐惧后撤。
关键动作防呆：涉及“夺物/夺兵/摘佩/缴械”时，必须在交错运动中完成（至少双方都在移动）；禁止一方站定、另一方慢动作取物。
