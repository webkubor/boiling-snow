# 第八集｜故纸惊鸿：杀手底色

## 🎬 剧情背景 (深度层级)
宁观尘点破“花神”顾栖月身份后，带慕夕歌转向丹阳城黑市。对他而言，查苏王爷的药材局固然重要，但借此机会潜入能交换天下信息的“暗坊”寻找姐姐的下落，才是他不惜冒犯王府的真正动力。

## 📝 详细交代
- **情感暗线**: 宁观尘看着夕歌，脑海中却闪过年少时姐姐为了半个馒头把自己卖掉的破碎画面。他接近夕歌本是因为“孤山门人”的身份在禁地极好使，但刚才下坠时，他下意识地挡在了夕歌上风口。
- **黑市见闻**: 两人穿过布满机关的枯井进入暗坊。宁观尘展示了身为顶级探子的统治力，他用一张老旧的情报网换取了关于“药路”背后的名字——夜惊鸿。
- **真相碰撞**: 故纸堆里，不仅有苏王爷的杀手前身，还隐藏着黑市多年前的一宗人口贩卖记录。宁观尘的手在颤抖，他离姐姐近了，却也离苏王爷的杀机更近了。

## 🏮 悬念与信息点
- **悬念**: 宁观尘的姐姐是否就在苏王爷控制的“多拨势力”中？
- **信息点**: 苏梦城的杀手代号“夜惊鸿”，在黑市是不可言说的禁忌。
