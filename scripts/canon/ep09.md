# 第九集｜暗坊深水：旧名与信物

## 🎬 本集定位
在暗坊深处，情报被揭开两层皮——南楚枪神的真实身份"夜惊鸿"被执事完整揭晓，同时宁观尘发现姐姐的关键信物。多方势力的杀意已至暗市。

## 🧩 剧情核心（按出场顺序）

1. **万宝楼情报交易**
   - 二人已进入万宝楼核心区
   - 看到天榜石台与各种信物（断箭、枪缨、刀环等）
   - 视觉呼应序章，强化"黑市评定天榜"的世界观

2. **南楚枪神的身份揭晓**
   - 宁观尘问："南楚枪神，到底是谁？"
   - 执事看向石台上的银色枪缨，缓缓道来：
     - "南楚枪神，江湖还有个旧名——夜惊鸿"
     - "十三年前，黑市查过他"
     - "但这后来不重要了——他不在黑榜上"
     - "夜惊鸿，上了天榜第二"
   - 二人面面相觑，一个名字牵出两层身份

3. **姐姐信物浮现**
   - 宁观尘眼角掠过石台上一枚旧木簪——那是他姐姐当年被卖时戴的
   - 他的表情瞬间凝固，手握酒葫芦收紧
   - 夕歌注意到他的异常，但默契地没有追问

4. **发榜动静上楼**
   - 楼下忽然喧起整齐呼声：发榜了
   - 慕夕歌低问："什么榜？" 宁观尘应："自然是黑榜。"
   - 屏风后人补一句："还有天榜。"

## 📌 本集硬信息
- 南楚枪神就是当年的"夜惊鸿"
- 夜惊鸿早期被黑市调查，但后来跃升为天榜第二，不再属于黑榜
- 宁观尘姐姐的信物出现在黑市
- 黑榜与天榜同夜发榜，黑市秩序进入高压时刻

## 🎣 集尾钩子
楼下“发榜”声一浪高过一浪。宁观尘握紧酒葫芦，夕歌按住剑柄，二人意识到这不是普通交易夜，而是整座黑市的规则夜。观众预期：下一集围绕榜单引发的新局正式开盘。

## 🎥 分镜设计（15s）

### 0.0-3.0s 【登楼·石台列阵】

**0.0-3.0s | 万宝楼中**
- **景别**：广角仰拍 → 中景 (MS) → 细节特写
- **画面**：
  - 二人沿木梯登楼，镜头广角仰拍展现万宝楼的空间纵深感
  - 楼上豁然开朗，万宝楼核心区展露
  - 石台中央，十件信物陈列：断箭、枪缨、刀环、笛穗、鞭扣...
  - **石台周围站着数位黑市中人，皆戴面具**——青铜面具、铁制面具、木刻面具、银饰面具，无一例外
  - 特写：一位戴青铜面具的执事缓缓转身，面具眼孔深处目光如针
  - 周围戴面具的江湖客静默如塑像，唯有呼吸白雾在冷光下若隐若现
- **运镜**：广角仰拍展现空间感→中景展现石台全貌→特写执事面具营造压迫感
- **光影**：丁达尔效应的冷光从高处天窗落下，石台如祭坛；面具上的金属光泽忽明忽暗
- **音效**：木梯吱呀声，冷风穿过高窗的呼啸声，远处轻微的呼吸声

---

### 3.0-9.0s 【夜惊鸿·身份揭晓】

**3.0-5.0s | 枪缨微光**
- **景别**：主观镜头 (POV) → 枪缨特写 → 过肩镜头 (OTS)
- **画面**：
  - 宁观尘开口："南楚枪神，到底是谁？"
  - 镜头主观视角，跟随宁观尘视线看向石台
  - 枪缨特写：银色枪缨在冷光下泛着微弱的银辉，丝线如血般细腻
  - 执事缓缓开口，声音低沉："南楚枪神，江湖还有个旧名——夜惊鸿"
  - 过肩镜头：执事站在二人身后，面具后的一双眼睛带着回忆
- **运镜**：主观视角营造探索感→枪缨特写强调线索→过肩镜头营造对话感
- **光影**：枪缨特写时银光微闪，象征夜惊鸿的存在；冷光打在执事面具上
- **音效**：执事声音低沉，带着回响；远处传来轻微的兵器碰撞声

**5.0-7.0s | 从黑榜到天榜**
- **景别**：执事面部特写（面具部分） → 石台全景 → 手势特写
- **画面**：
  - 执事继续："十三年前，黑市查过他"
  - 镜头缓缓拉开，石台上十件信物尽收眼底
  - "但这后来不重要了——他不在黑榜上"
  - 执事抬手指向石台最高处
  - "夜惊鸿，上了天榜第二"
  - 特写：执事戴手套的手指指向最高处，指尖微颤
- **运镜**：执事特写→缓缓拉开展现石台全貌→手势特写强调位次
- **光影**：拉镜时冷光渐强；手势特写时光影在指缝间流转
- **音效**：执事声音渐强，"天榜第二"四字回响；远处传来一声模糊的枪鸣幻觉音

**7.0-9.0s | 震惊对视**
- **景别**：双人中景 (2S) → 快速正反打 → 眼部特写
- **画面**：
  - 宁观尘与夕歌面面相觑
  - 镜头在两人面部之间快速切换
  - 二人眼中皆是震惊——一个名字，两层身份
  - 特写宁观尘眼神：瞳孔微缩，思绪万千
  - 特写夕歌眼神：震惊与思索交织
  - 夕歌握剑的手微微收紧，剑鞘发出轻微摩擦声
- **运镜**：双人中景→快速正反打营造紧张感→眼部特写深化情绪
- **光影**：冷光打在两人脸上，神情清晰
- **音效**：无对白，只有呼吸声和剑鞘摩擦声

---

### 9.0-15.0s 【信物·杀机暗涌】

**9.0-11.0s | 旧木簪**
- **景别**：宁观尘主观视角 → 石台微距特写 → 面部微表情特写 → 手部特写
- **画面**：
  - 宁观尘视线突然停在石台边缘
  - 微距特写：一枚旧木簪，木纹斑驳，顶端雕刻着一朵残败的桃花
  - 木簪上有轻微的磕痕，边角磨损——那是姐姐常年戴着的结果
  - 切至宁观尘面部：表情瞬间凝固，瞳孔收缩，下颌微微收紧
  - 特写：他握着酒葫芦的手指节发白，指节微微颤抖
  - 酒葫芦中的酒水因颤抖激起微微涟漪，在皮革表面映出 distorted 的倒影
- **运镜**：主观视角→微距特写→面部特写→手部特写，层层递进，情绪升级
- **光影**：木簪在冷光下显得孤寂；宁观尘面部阴影加深；酒葫芦涟漪反光
- **音效**：无音效，只有呼吸声突然停滞，随后是缓慢的、沉重的呼吸；酒葫芦内酒水轻微晃动声

**11.0-12.5s | 默契不问**
- **景别**：夕歌视角 (夕歌POV) → 夕歌眼部特写 → 双人侧拍
- **画面**：
  - 夕歌注意到宁观尘的异常
  - 她的目光落在那枚木簪上，又回到宁观尘脸上
  - 特写夕歌的眼神——带着询问，但带着克制与温柔
  - 她微微摇头，轻轻拍了拍宁观尘的肩膀
  - 宁观尘深吸一口气，缓缓松开紧握的酒葫芦
  - 双人侧拍：二人并肩而立，一白衣一青袍，在石台前沉默
- **运镜**：夕歌主观视角→眼部特写→双人侧拍，情感递进
- **光影**：夕歌眼神在冷光下显得清澈而温柔；双人侧拍时冷光勾勒二人身姿
- **音效**：酒葫芦放松时的轻微碰撞声；二人的呼吸声同步

**12.5-15.0s | 楼下发榜**
- **景别**：楼上俯拍 → 门缝外长廊中景 → 双人近景 → 屏风剪影定格
- **画面**：
  - 楼下先起一阵整齐呼声："发榜了！"
  - 镜头透过门缝看向长廊，戴面具人群开始向榜墙方向聚拢，秩序压抑、并不混乱
  - 慕夕歌侧目低问："什么榜？"
  - 宁观尘压低声音回："自然是黑榜。"
  - 屏风后人补一句："还有天榜。"
  - 话音落下，烛火轻晃，门外脚步骤密，画面定在半开门缝与屏风剪影之间
- **运镜**：俯拍建立空间→门缝窥视增强临场感→双人近景承接台词→屏风定格收尾
- **光影**：门外暖色灯笼与屋内冷色烛光形成冷暖断层；屏风后轮廓始终不现真容
- **音效**：楼下"发榜了"呼声由远及近，木地板脚步声叠加低频鼓点；台词近讲克制，结尾留白半拍
