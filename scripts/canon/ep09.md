# 第九集｜暗坊深水：旧名与信物

## 🎬 本集定位
在暗坊深处，情报被揭开两层皮——南楚枪神的真实身份"夜惊鸿"被执事完整揭晓，同时宁观尘发现姐姐的关键信物。多方势力的杀意已至暗市。

## 🧩 剧情核心（按出场顺序）

1. **万宝楼情报交易**
   - 二人已进入万宝楼核心区
   - 看到天榜石台与各种信物（断箭、枪缨、刀环等）
   - 视觉呼应序章，强化"黑市评定天榜"的世界观

2. **南楚枪神的身份揭晓**
   - 宁观尘问："南楚枪神，到底是谁？"
   - 执事看向石台上的银色枪缨，缓缓道来：
     - "南楚枪神，江湖还有个旧名——夜惊鸿"
     - "十三年前，黑市查过他"
     - "但这后来不重要了——他不在黑榜上"
     - "夜惊鸿，上了天榜第一"
   - 二人面面相觑，一个名字牵出两层身份

3. **姐姐信物浮现**
   - 宁观尘眼角掠过石台上一枚旧木簪——那是他姐姐当年被卖时戴的
   - 他的表情瞬间凝固，手握酒葫芦收紧
   - 夕歌注意到他的异常，但默契地没有追问

4. **暗杀阴影降临**
   - 楼下传来骚动，三拨暗流势力同时现身
   - 执事低语："看来有人也想知道这些消息..."
   - 集尾镜头：三方人影从不同方向逼近，楼上楼下杀机涌动

## 📌 本集硬信息
- 南楚枪神就是当年的"夜惊鸿"
- 夜惊鸿早期被黑市调查，但后来跃升为天榜第一，不再属于黑榜
- 宁观尘姐姐的信物出现在黑市
- 多方势力已盯上他们的情报线

## 🎣 集尾钩子
三方人影逼近，楼下杀机涌动。宁观尘握紧酒葫芦，夕歌按住剑柄——暗坊即将变成杀场。观众预期：下一集将爆发三方混战。

## 🎥 分镜设计（15s）

### 0.0-3.0s 【登楼·石台列阵】

**0.0-3.0s | 万宝楼中**
- **景别**：广角仰拍 → 中景 (MS) → 细节特写
- **画面**：
  - 二人沿木梯登楼，镜头广角仰拍展现万宝楼的空间纵深感
  - 楼上豁然开朗，万宝楼核心区展露
  - 石台中央，十件信物陈列：断箭、枪缨、刀环、笛穗、鞭扣...
  - **石台周围站着数位黑市中人，皆戴面具**——青铜面具、铁制面具、木刻面具、银饰面具，无一例外
  - 特写：一位戴青铜面具的执事缓缓转身，面具眼孔深处目光如针
  - 周围戴面具的江湖客静默如塑像，唯有呼吸白雾在冷光下若隐若现
- **运镜**：广角仰拍展现空间感→中景展现石台全貌→特写执事面具营造压迫感
- **光影**：丁达尔效应的冷光从高处天窗落下，石台如祭坛；面具上的金属光泽忽明忽暗
- **音效**：木梯吱呀声，冷风穿过高窗的呼啸声，远处轻微的呼吸声

---

### 3.0-9.0s 【夜惊鸿·身份揭晓】

**3.0-5.0s | 枪缨微光**
- **景别**：主观镜头 (POV) → 枪缨特写 → 过肩镜头 (OTS)
- **画面**：
  - 宁观尘开口："南楚枪神，到底是谁？"
  - 镜头主观视角，跟随宁观尘视线看向石台
  - 枪缨特写：银色枪缨在冷光下泛着微弱的银辉，丝线如血般细腻
  - 执事缓缓开口，声音低沉："南楚枪神，江湖还有个旧名——夜惊鸿"
  - 过肩镜头：执事站在二人身后，面具后的一双眼睛带着回忆
- **运镜**：主观视角营造探索感→枪缨特写强调线索→过肩镜头营造对话感
- **光影**：枪缨特写时银光微闪，象征夜惊鸿的存在；冷光打在执事面具上
- **音效**：执事声音低沉，带着回响；远处传来轻微的兵器碰撞声

**5.0-7.0s | 从黑榜到天榜**
- **景别**：执事面部特写（面具部分） → 石台全景 → 手势特写
- **画面**：
  - 执事继续："十三年前，黑市查过他"
  - 镜头缓缓拉开，石台上十件信物尽收眼底
  - "但这后来不重要了——他不在黑榜上"
  - 执事抬手指向石台最高处
  - "夜惊鸿，上了天榜第一"
  - 特写：执事戴手套的手指指向最高处，指尖微颤
- **运镜**：执事特写→缓缓拉开展现石台全貌→手势特写强调第一
- **光影**：拉镜时冷光渐强；手势特写时光影在指缝间流转
- **音效**：执事声音渐强，"天榜第一"四字回响；远处传来一声模糊的枪鸣幻觉音

**7.0-9.0s | 震惊对视**
- **景别**：双人中景 (2S) → 快速正反打 → 眼部特写
- **画面**：
  - 宁观尘与夕歌面面相觑
  - 镜头在两人面部之间快速切换
  - 二人眼中皆是震惊——一个名字，两层身份
  - 特写宁观尘眼神：瞳孔微缩，思绪万千
  - 特写夕歌眼神：震惊与思索交织
  - 夕歌握剑的手微微收紧，剑鞘发出轻微摩擦声
- **运镜**：双人中景→快速正反打营造紧张感→眼部特写深化情绪
- **光影**：冷光打在两人脸上，神情清晰
- **音效**：无对白，只有呼吸声和剑鞘摩擦声

---

### 9.0-15.0s 【信物·杀机暗涌】

**9.0-11.0s | 旧木簪**
- **景别**：宁观尘主观视角 → 石台微距特写 → 面部微表情特写 → 手部特写
- **画面**：
  - 宁观尘视线突然停在石台边缘
  - 微距特写：一枚旧木簪，木纹斑驳，顶端雕刻着一朵残败的桃花
  - 木簪上有轻微的磕痕，边角磨损——那是姐姐常年戴着的结果
  - 切至宁观尘面部：表情瞬间凝固，瞳孔收缩，下颌微微收紧
  - 特写：他握着酒葫芦的手指节发白，指节微微颤抖
  - 酒葫芦中的酒水因颤抖激起微微涟漪，在皮革表面映出 distorted 的倒影
- **运镜**：主观视角→微距特写→面部特写→手部特写，层层递进，情绪升级
- **光影**：木簪在冷光下显得孤寂；宁观尘面部阴影加深；酒葫芦涟漪反光
- **音效**：无音效，只有呼吸声突然停滞，随后是缓慢的、沉重的呼吸；酒葫芦内酒水轻微晃动声

**11.0-12.5s | 默契不问**
- **景别**：夕歌视角 (夕歌POV) → 夕歌眼部特写 → 双人侧拍
- **画面**：
  - 夕歌注意到宁观尘的异常
  - 她的目光落在那枚木簪上，又回到宁观尘脸上
  - 特写夕歌的眼神——带着询问，但带着克制与温柔
  - 她微微摇头，轻轻拍了拍宁观尘的肩膀
  - 宁观尘深吸一口气，缓缓松开紧握的酒葫芦
  - 双人侧拍：二人并肩而立，一白衣一青袍，在石台前沉默
- **运镜**：夕歌主观视角→眼部特写→双人侧拍，情感递进
- **光影**：夕歌眼神在冷光下显得清澈而温柔；双人侧拍时冷光勾勒二人身姿
- **音效**：酒葫芦放松时的轻微碰撞声；二人的呼吸声同步

**12.5-15.0s | 楼下杀机**
- **景别**：楼上俯拍全景 → 底楼多角度快速蒙太奇 → 暗中眼眸 → 黑暗收尾
- **画面**：
  - 突然，楼下传来一声闷响——重物落地声
  - 镜头从楼上俯拍，透过楼板缝隙向下望去
  - 快速蒙太奇（每帧0.5秒）：
    - 入口处，三个戴黑色铁面具的人影踏步而入，身披黑袍
    - 另一侧，两个戴银色布面罩的人影无声靠近，手按刀柄
    - 还有一处，一个戴铜制兽面具的人影从暗巷中走出，手持长鞭
  - 所有新来者都戴着面具，面目模糊，杀意却清晰可见
  - 切回楼上，执事嘴角微微上扬（面具下颌处可见一丝弧度）：
    - "看来有人也想知道这些消息..."
  - 镜头快速后拉，万宝楼全貌展现
  - 石台、信物、执事、宁观尘与夕歌、楼下的三方人影——同框
  - 黑暗中，无数双戴面具的眼睛向同一处聚焦
  - 最后一个镜头：黑暗中，一双戴青铜面具的眼睛缓缓眨了一下
  - 画面在一片黑暗中收尾，只有石台上银色枪缨微光闪烁
- **运镜**：俯拍展现全貌→快速蒙太奇制造紧张感→快速后拉展现杀局→眼眸特写收尾
- **光影**：黑暗吞噬一切，只有枪缨银光残留；最后的眼眸特写有微弱的反光
- **音效**：楼下闷响→快速脚步声（三波不同节奏）→兵器出鞘声→一片死寂，只有风吹过高窗的呼啸→最后一声轻微的眨眼声
