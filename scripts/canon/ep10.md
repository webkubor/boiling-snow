# 第十集｜代价开口：旧账启动

## 本集已锁定剧情（待补时长）

### 片段1（黑市对峙）
- 承接第九集“夜惊鸿”揭名后。
- 宁观尘发问：关于姐姐宁子瑜。
- 执事拒收钱，只收代价。
- 执事开价：要慕夕歌的剑。

### 片段2（关系撕裂）
- 慕夕歌拒绝交剑。
- 宁观尘改押自己的命，换一条线索。
- 慕夕歌阻拦。
- 宁观尘说出“我一开始就在利用你，利用孤山”。
- 慕夕歌震惊失望，关系破裂。

### 片段3（王府切线）
- 场景切王府演武场。
- 苏梦城问：亲卫训练是否过猛。
- 顾栖月回应：王爷安危优先。
- 萧烬弦回应：有人坐稳位置，别忘旧恩。
- 苏梦城落锤：“既然上面那位想查旧账，那便去查。苏某人，已经没什么顾忌了。王府内外，按战时规矩。”

### 片段4（集尾钩子）
- 慕夕歌离开黑市后看到发榜墙。
- 榜单出现“孤山剑首”刺杀悬赏，赏金万两黄金。
- 她按剑不拔，意识到师兄已被盯上。

## 执行规则（本集专用）
- 剧情优先，不炫技优先。
- 对话段落优先采用“固定场景 + 固定站位 + 少切镜”。
- 黑市内厅规则：执事在屏风后，宁观尘与慕夕歌在屏风另一侧。
- 人物外观以参考图为准；命令内不重复描述服装细节。
- 全程无BGM，使用场景音与兵器/脚步拟音推进压迫感。
