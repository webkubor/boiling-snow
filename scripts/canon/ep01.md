# 第一集：雪夜传说：三杰约战已成

## 🎬 剧情核心
名号已立、旧怨已成，雪夜杀机先落。这一集不讲过程，先给“结果感”：全江湖都知道这场局要爆。

## 📝 详细交代
- **世界观铺陈**：大雪边关，残旗猎猎。旁白交代天下三分（西燕、南楚、北荒）的紧绷局势。
- **名号确立**：通过边境将领的密谈与恐惧，侧面勾勒出“三杰”的恐怖战力：孤山剑首的冷、西燕狂刀的狠、南楚枪神的玄。
- **约战伏笔**：三方势力的信物在雪夜中交汇，虽然人未到，但“约战天门关”的消息已如瘟疫般传遍武林。

## 🏮 悬念与信息点
- **悬念**：三杰之间的“旧怨”到底是什么？
- **信息点**：金印（密信）的出现，预示着这场战斗不仅是武林争霸，更是国运博弈。
