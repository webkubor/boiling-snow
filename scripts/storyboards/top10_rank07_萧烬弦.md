# 《沸腾之雪》天榜十绝·天榜第七·萧烬弦（15s）正式版

## 🎬 核心设计理念
- **视觉逻辑**：极致的“冷色调”与“金属质感”。强调箭簇的寒光、指尖的稳健、以及鲜血溅在雪地上的高饱和反差。
- **动态节奏**：0-9秒为极静的蓄力与远射，9-12秒为极速的近身瞬杀，12-15秒回归死寂。
- **环境背景**：苏王府飞檐之上，大雪封路，瓦片覆冰。

## 🎥 镜头分解 (15s)

### 0.0-3.0s 【位：屋脊孤狼】
- **景别**：特写 (CU) -> 远景 (LS)。
- **画面**：特写萧烬弦缠满玄色护腕的手，缓缓扣住弓弦；镜头拉远，他身披重磅黑狼毫领大氅，单膝跪在苏王府冰冷的青瓦脊背上，满弦如月，箭尖对准斜下方的阴影。
- **音效**：沉重的风雪呼啸，弓弦受力发出的牙酸挤压声。

### 3.0-6.0s 【定：杀机满弦】
- **景别**：极端特写 (ECU)。
- **画面**：箭簇上的寒光映射出远方闯入者的身影（模糊残影）。萧烬弦的双眼微阖，睫毛上挂着细小冰晶。画面色彩降到极致，唯有那一线杀意是清亮的。
- **音效**：呼吸声完全消失，只剩风声。

### 6.0-9.0s 【爆：瞬箭封喉】
- **景别**：跟随镜头 (Tracking) -> 特写。
- **画面**：指尖松开，箭矢破空而去，带起一道细长的雪雾旋涡。镜头极速跟随箭簇，猛然钉入远方回廊的木柱，箭羽在震动中带出点点血珠。
- **音效**：如雷鸣般的“嗡”一声爆响，随后是利箭入木的沉重钝响。

### 9.0-12.0s 【瞬：近身止杀】
- **景别**：快切 (Quick Cuts)。
- **画面**：萧烬弦身形已失。下一帧，他在回廊阴影中现身，右手食指与中指并拢，精准点在另一名敌人的咽喉。指尖发力，空气仿佛凝固。
- **音效**：三声极短的重鼓点。骨骼碎裂的微响。

### 12.0-15.0s 【收：雪落余音】
- **景别**：中景 -> 侧脸特写。
- **画面**：萧烬弦缓缓收手，隐入廊柱后的黑暗。镜头给到廊柱上仍在微微颤动的箭羽。结尾处，他侧身回眸，眼底一片冰冷，画面定格在**【绝】**字视觉符号上（水墨虚化）。
- **音效**：风雪声重新推高，盖过所有余音。

## 📝 技术 specifications
- **规格**：2.39:1 / 24fps / 4K 电影级渲染。
- **色彩规范**：黑、玄青、冷银、高饱和血红。
- **物理反馈**：箭羽振动频率必须符合强弓物理特性，指法点杀要有血雾瞬间爆开的雾化感。
