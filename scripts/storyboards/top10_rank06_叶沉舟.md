# 《沸腾之雪》天榜十绝·天榜第06·叶沉舟（15s）正式版

## 🎬 核心设计理念
- **视觉逻辑**：**“层峦叠浪的推进感”**。刀法如潮汐，一浪高过一浪。强调苗刀的修长美感与劈砍时的共振位移。
- **动态节奏**：极具韵律感的劈砍，动作大开大合。
- **环境背景**：怒海礁石之上，巨浪不断拍打，背景是深蓝色的惊涛骇浪。

## 🎥 镜头分解 (15s)

### 0.0-3.0s 【观：潮起一线】
- **景别**：极端全景 (EFS)。
- **画面**：叶沉舟立于突兀的礁石尖端，修长的“观潮”横握。背后一道数丈高的巨浪正欲拍下。镜头极速推进至刀面特写，大马士革纹路如海浪般起伏。
- **音效**：排山倒海的浪涛声，海水撞击岩石的轰鸣。

### 3.0-6.0s 【破：逆浪横刀】
- **景别**：中景 (MS)。
- **画面**：巨浪拍下的瞬间，叶沉舟逆势挥刀。苗刀修长的弧线划破水幕，将万吨海水从中劈开一条缝隙。水花四溅中，他的眼神冷峻如冰。
- **音效**：利刃切断水幕的清脆裂响，水流激荡。

### 6.0-9.0s 【连：九重叠浪】
- **景别**：动态跟随镜头。
- **画面**：面对围攻的刀客，叶沉舟身随刀走，连续三次势大力沉的斜劈。每一刀都精准叠加在上一刀的余劲上。镜头展现刀尖带出的细长水线。
- **音效**：连续三声沉重的金属共鸣，频率递增。

### 9.0-12.0s 【崩：怒涛拍岸】
- **景别**：特写 (CU) -> 广角。
- **画面**：最后一记重劈。刀刃落地的瞬间，礁石竟被劈开一道裂缝，强劲的刀气将周围的海水震起数米高。
- **音效**：沉重的岩石开裂声，水体爆炸声。

### 12.0-15.0s 【定：沉舟一掷】
- **景别**：中景侧写。
- **画面**：叶沉舟收刀入鞘，海风吹乱他的长发。巨浪在他背后平息。画面定格在**【潮】**字视觉符号上。
- **音效**：海鸟哀鸣，浪花退去的沙沙声。

## 📝 技术 specifications
- **规格**：2.39:1 / 24fps / 4K。
- **色彩规范**：深海蓝、岩石灰、泡沫白。
- **物理反馈**：水流的切割反馈必须真实，刀气震水的效果要有空间压迫感。
