# 《沸腾之雪》天榜十绝·天榜第08·陆听潮（15s）正式版

## 🎬 核心设计理念
- **视觉逻辑**：**“暴雨中的割裂感”**。利用雨滴被刀刃切开的物理特效，强调高频旋转与优雅的疯批感。色彩倾向于暗绿与泥泞灰。
- **动态节奏**：旋转、旋转、再旋转。像龙卷风一样在敌阵中切割。
- **环境背景**：西燕南部的泥沼湿地，暴雨如注，视野极低。

## 🎥 镜头分解 (15s)

### 0.0-3.0s 【起：残响初鸣】
- **景别**：极端特写 (ECU)。
- **画面**：特写双持短刃“残响”的共振槽，密集的雨滴流过槽口，刀身发出细微的颤鸣。陆听潮站在齐膝深的泥水中，嘴角挂着一丝神经质的微笑。
- **音效**：密集的雨击声，金属高频颤鸣的“嘤——”声。

### 3.0-6.0s 【舞：雨幕绞杀】
- **景别**：环绕中景 (Orbital MS)。
- **画面**：陆听潮身形如陀螺般旋转，双刀在空中舞出两道银色圆环。雨幕被刀锋暴力切开，形成一圈向外扩散的水雾。
- **音效**：刀锋划破空气的尖锐哨音，水花被暴力击碎的声音。

### 6.0-9.0s 【裂：高频切割】
- **景别**：近景特写 (CU)。
- **画面**：陆听潮穿梭于四名刀手之间，动作极快。双刀在目标胸前、喉部留下无数细密的切割痕。镜头给到慢动作：雨水在触碰到刀刃的一瞬间被震碎成细雾。
- **音效**：连续不断的“哧——”声，像利刃划过丝绸。

### 9.0-12.0s 【崩：共振瞬杀】
- **景别**：极速推进特写。
- **画面**：陆听潮双刀交叉锁住敌方重兵，刀身共振槽疯狂颤动。下一秒，他发力向外拉扯，敌方兵刃竟因高频共振当场崩断。
- **音效**：清脆的金属断裂声，爆裂的重音。

### 12.0-15.0s 【定：狂气收场】
- **景别**：中景 -> 仰拍特写。
- **画面**：陆听潮停下动作，双刀反握。雨水洗刷着刀上的血迹。他仰头任由雨水冲刷脸庞，发丝紧贴额头。画面定格在**【鸣】**字视觉符号上。
- **音效**：雷声由远及近，风声凄厉。

## 📝 技术 specifications
- **规格**：2.39:1 / 24fps / 4K。
- **色彩规范**：泥沼绿、冷雨灰、刀刃亮银。
- **物理反馈**：刀身颤鸣要配合画面高频微震，雨滴切开效果需符合物理渲染。
