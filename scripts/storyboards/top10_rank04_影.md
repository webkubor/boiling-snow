# 《沸腾之雪》天榜十绝·天榜第四·影（15s）正式版

## 🎬 核心设计理念
- **视觉逻辑**：**“暗影中的毒蛇”**。全片影调极低，利用深不可测的黑色与偶尔闪现的金属冷光。强调无声的潜入与绝对致命的瞬杀。
- **动态节奏**：0-6秒为完全的潜行与侦察，6-12秒为“三连点杀”，12-15秒消失于阴影。
- **环境背景**：皇宫深处，红墙黑瓦，月光被厚厚的云层遮挡，仅有极少数宫灯摇曳。

## 🎥 镜头分解 (15s)

### 0.0-3.0s 【影：暗中蛰伏】
- **景别**：极端特写 (ECU) -> 低机位俯拍。
- **画面**：镜头贴在红墙瓦槽边缘，一只漆黑的乌金袖口滑过，无声无息。随后镜头下拉，俯视空旷的汉白玉廊桥，宫灯微晃，一个近乎透明的黑影贴着梁柱极速掠过。
- **音效**：极轻的衣料摩擦声，像蛇在草丛穿行；宫灯纸面受风的沙沙声。

### 3.0-6.0s 【机：杀机定格】
- **景别**：微距特写 (Macro CU)。
- **画面**：特写“蛰龙”短刺从袖中无声滑出。玄黑色刺身不反射任何光线，只有其锋利的边缘切割了流动的冷雾。镜头上移至“影”的眼部，唯有一双冰冷、毫无波动的瞳孔在黑暗中闪动。
- **音效**：金属划过丝绸的极细声响，令人不寒而栗的静寂。

### 6.0-9.0s 【瞬：三棱夺命】
- **景别**：快速横移跟拍 (Fast Panning)。
- **画面**：影从梁上垂直坠落，身形在空中呈螺旋状。落地瞬间，“蛰龙”第一刺扎入敌方护卫颈侧，第二刺顺势回旋刺穿后心，动作连贯如机械。敌方甚至未能发出声音。
- **音效**：沉闷的血肉贯穿声，重物软绵绵倒地的闷响，ducking 4dB 突出入肉声。

### 9.0-12.0s 【杀：蛰龙崩血】
- **景别**：特写 -> 慢动作 (Slo-mo)。
- **画面**：影在近身缠斗中左手扣住最后一名敌人的面门，右手“蛰龙”极速崩击，刺入对方肋间。镜头给到伤口细节：三棱结构带出的鲜血呈扇形喷溅，但瞬间被影的黑袍遮挡。
- **音效**：短促的骨骼碎裂声，鲜血喷涌的细微气泡音。

### 12.0-15.0s 【消：影入皇图】
- **景别**：大全景 (LS) -> 极速后拉。
- **画面**：影将短刺收入袖中，一甩斗篷，整个人凭空向后方黑暗跃入。镜头极速后拉，整座皇宫如同一张巨大的阴影网。画面定格在**【幽】**字视觉符号上。
- **音效**：风声突然推高，随后是一声空洞的宫铃声。

## 📝 技术 specifications
- **规格**：2.39:1 / 24fps / 4K。
- **色彩规范**：宫墙红、阴影黑、金属乌青。
- **物理反馈**：短刺刺入要有明显的阻力感与贯穿后的阻尼感，严禁任何光效。
