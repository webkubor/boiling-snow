# 《沸腾之雪》天榜十绝·天榜第02·欧阳狂徒（15s）正式版

## 🎬 核心设计理念
- **视觉逻辑**：**“原始的暴力与毁灭”**。画面充满颗粒感与焦灼感。强调“重刃”的物理重量与劈砍后的视觉爆炸。
- **动态节奏**：野兽般的爆发。不讲究章法，每一刀都是倾尽全力的毁灭。
- **环境背景**：古战场废墟，残垣断壁，地面满是焦土与尚未熄灭的余火，天空阴云压城。

## 🎥 镜头分解 (15s)

### 0.0-3.0s 【狂：黑刀破军】
- **景别**：低机位仰拍 (Low Angle)。
- **画面**：欧阳狂徒单手拖着门板大小的“破军”大刀。黑铁刀身划过焦土，带起火星与烟尘。他赤裸的上半身肌肉虬结，布满战斗伤疤。
- **音效**：沉重的金属拖地声（Grinding），沉重的野兽般喘息。

### 3.0-6.0s 【震：大地崩裂】
- **景别**：中景 (MS)。
- **画面**：欧阳狂徒发力跃起，双手握刀，在半空中如一张拉满的黑弓。落地的一瞬，大刀暴力砸入地面。以落点为中心，地面焦土瞬间掀起数米高的尘浪。
- **音效**：震耳欲聋的轰鸣声，地面塌陷的巨响。

### 6.0-9.0s 【碎：血雾屠戮】
- **景别**：特写 -> 升格 (Slo-mo)。
- **画面**：面对重甲铁骑，欧阳狂徒横向暴虐一挥。刀锋未至，纯粹的重量动能已将敌人的盔甲砸瘪。画面呈现鲜血在空中被暴力震碎成红雾的视觉特效。
- **音效**：金属被强行砸扁的刺耳扭曲声，骨骼碎裂声。

### 9.0-12.0s 【崩：万夫莫敌】
- **景别**：动态大广角。
- **画面**：欧阳狂徒在敌阵中横冲直撞，每一次挥刀都带起破碎的盔甲碎片与木屑。他如同黑色旋风，所到之处皆为齑粉。
- **音效**：密集的撞击声与惨叫声，低频的震撼音效。

### 12.0-15.0s 【定：狂徒之怒】
- **景别**：近景仰拍特写。
- **画面**：欧阳狂徒将大刀往地上一杵，单手抹过脸上的血迹，露出一口白牙残忍一笑。背后是硝烟弥漫的废墟。画面定格在**【狂】**字视觉符号上。
- **音效**：战场远处的号角声，火烧木头的噼啪声。

## 📝 技术 specifications
- **规格**：2.39:1 / 24fps / 4K。
- **色彩规范**：焦土地黑、火焰橘、高饱和血红。
- **物理反馈**：刀砸地的震屏感必须强烈，血液被震碎成雾的视觉效果要写实。
