# 顾栖月·百丈漈出场动作模板 (Action Template)

## 核心设计理念
- **视觉重心**：素白劲装 vs 纯黑刺客，白瀑青崖间的明暗博弈。
- **武器系统**：羊脂玉笛（攻防核心），墨色青油纸伞（视觉挂件/防御伏笔）。
- **气场设定**：清冷、凌厉、动作干脆（非柔弱感），强调“笛随影动”。

## 场景配置
- **地点**：文成百丈漈（实景参考）。
- **元素**：飞瀑、云气、青藤、苔石、潭水、山风。

## 详细脚本 (15秒)

| 时间 (秒) | 镜头语言 | 动作表现 | 卡点节奏 |
| :--- | :--- | :--- | :--- |
| **0-3s 起势** | 横版全景，侧脸特写切定格背影。 | 立于瀑口掠出，右手旋笛，穿梭水雾。 | 0s(笛), 1.5s(转身), 3s(腾空) |
| **3-6s 破影** | 180°环绕中景，仰拍腾空。 | 贴地避袭，玉笛横挡，翻身笛尾扫雾。 | 3.5s(刺客), 5s(滑行), 6s(护体) |
| **6-9s 逐杀** | 快速推进+穿崖缝跟拍，群袭拉宽。 | 玉笛挥出莹白幕帘格挡，点刺逼退众敌。 | 6.5s(群袭), 7.5s(笛幕), 9s(逼退) |
| **9-12s 收势** | 缓拉远景切极速推近特写。 | 震退最后一人，跃立崖边，玉笛直立。 | 9.5s(退散), 11s(笛立), 12s(定格) |
| **12-15s 终章** | 特写拉远回归全景。 | 缓缓回眸，左手扶伞右手握笛，衣摆轻扬。 | 13s(回眸), 15s(收尾) |

## 音效与BGM
- **BGM**：高燃国风重鼓（适配《侠骨行》/《山河令》高潮）。
- **音效**：瀑布鸣、笛音、兵器碰撞、碎石滚落、破风声。
