# 沸腾之雪 · 打斗戏拍摄 SOP（标准作业流程）

> 任何人/AI 拿到本 SOP，按步骤执行即可产出质量达标的打斗短片。
> 无需灵感，不靠随性发挥。规则即质量。

---

## STEP 0：前置检查（写脚本之前）

在动笔之前，确认以下信息：

- [ ] **场景**：地形 + 光照 + 气氛（从地形库§5中选或自定义）
- [ ] **人物**：角色身份 + 武器（从武器谱§6中查物理逻辑）
- [ ] **敌方**：数量 + 武器 + 站位 + 出场顺序
- [ ] **时长**：15s（默认）/ 30s / 60s
- [ ] **情绪基调**：杀意 / 冷静 / 绝望 / 试探 / 愤怒（从§7中选）

---

## STEP 1：时间分配（一分不能浪费）

### 15秒标准模板

| 时段 | 秒数 | 做什么 | 禁止做什么 |
|------|------|--------|-----------|
| **起势** | 0-2s | 交代环境 + 人物就位 + **首次接触** | ❌ 空拍摆 pose、慢镜头铺垫、超过2s |
| **激战** | 2-13s | **全片精华**，连续攻防交换 | ❌ 超过1s无攻防交换、回合制 |
| **收尾** | 13-15s | 结果定格 + 环境余韵 | ❌ 拖过2s、大远景空镜 |

### 激战期硬约束（2-13秒）
- 每2秒 ≥ 1次有效攻防交换（接触 / 破招 / 反制）
- 单招时长 0.3-0.6秒
- 双方同时移动同时出手，禁止回合制

---

## STEP 2：分配视觉资源

在 2-13秒的激战期中，分配以下三种"特殊镜头"的配额：

| 资源 | 15s配额 | 位置 | 必须包含 |
|------|---------|------|---------|
| **慢镜头** | 最多1次，0.2-0.35s | 打斗中间（5-10s） | 武器接触瞬间的微观打击效果 |
| **史诗镜头** | 最多1次，1-2s | 打斗高潮（7-10s） | 大景别全景 + 人物 + 战斗痕迹 + 环境 |
| **表情特写** | 最多1次，≤0.3s | 打斗中间 | 杀意闪过 / 锁定目标 / 被击中的反应 |

**铁律**：
- ❌ 慢镜头禁止用于起势摆拍和收尾回眸
- ❌ 史诗镜头禁止纯环境空镜（必须有人）
- ❌ 表情特写禁止用于起势和收尾
- ✅ 其余时间全部给**战斗特写**（剑尖划过血线、刀背格挡手臂绷紧、弩箭撕裂衣角）

---

## STEP 3：选运镜方案

每3秒一段，每段只选**一种**运镜，不要堆砌。

| 打斗场景 | 推荐运镜 | 原因 |
|---------|---------|------|
| 对穿抢位 | 中景侧跟 | 能看到双方位移和距离变化 |
| 轻功腾空 | 低机位仰拍 | 突出高度和速度感 |
| 近身破招 | 贴身短焦 | 武器距离内的打击细节 |
| 群战调度 | 高机位俯拍 | 看清多人站位和阵型变化 |
| 史诗高潮 | 大远景俯拍 | 展示场景宏大尺度 |
| 收尾定格 | 缓拉中景 | 自然收束 |

**切镜频率**：15秒片 3-5次切镜，不超过7次。每次切镜必须有信息增量。

---

## STEP 4：编写脚本（强制格式）

### 4.1 设计稿格式（内部审核用）

每一段按以下格式编写，用于设计、自检、团队对齐：

```markdown
## 第N段 [Xs-Ys]｜段名

**动作**：
- [主方] 物理描述：身体部位 + 方向 + 力度 + 接触点
- [敌方编号] 物理描述：身体部位 + 方向 + 力度 + 接触点
- 环境反馈：由动作触发的物理反应

**运镜**：[一种，≤10字]
**特写**：[战斗/环境/表情] + [画面描述，≤0.5s]
```

### 4.2 最终交付格式（直接丢给视频生成工具）

设计稿通过 STEP 7 自检后，必须转写成以下**连续叙事格式**交付。
这是视频生成工具能直接读取的标准格式，一段完整的 prompt，不分段不拆行。

```markdown
请在[场景参考图]场景中，使用[人物参考图]物做这段视频：场景：[地形+光照+天气+氛围]。人物：[角色外貌+服装+武器]。敌方：[数量+武器+初始站位]。音效：[场景音+兵器音+环境音]。技术：[分辨率+色彩+胶片+帧率+风格]。0-2s｜段名 [运镜]。[连续动作描述，主方和敌方交替，包含物理量，环境反馈融入动作中]。2-5s｜段名 [运镜]。[同上]。...13-15s｜段名 [运镜]。[同上]。
```

**交付格式红线**：
- **纯文本，不分段不换行**，整段 prompt 复制即用
- **无卡点标注**（"卡点：0s→1s→2s" 之类全部删掉）
- 每段时间标题保留（如"0-2s｜雨夜·已在杀"），但紧跟运镜和动作，不另起行
- 环境反馈融入动作描述中，不单独写"环境反馈：xxx"

### 格式红线：
- 动作描述**只用物理量**，禁止比喻（"右脚蹬竹竿向左45°弹起3米" ✅ / "如白鹤掠水" ❌）
- 敌人**必须写具体动作**（几个、站哪、用什么招、怎么出），禁止"黑影浮现""刀手压上"
- 环境反馈**必须由动作触发**，禁止凭空出现
- 每段**只写一种运镜**，禁止堆砌
- 交付格式中每段是一段**连续文字**，不要用列表/分栏/加粗拆开

---

## STEP 5：轻功处理（如涉及）

角色使用轻功时，强制遵守以下链条：

```
蹬地起跳（必须写踩了什么） → 空中变线（必须有物理惯性） → 落地接招（必须有落点反馈）
```

| 要求 | 说明 |
|------|------|
| 物理反馈 | 0.3-0.6秒内必须与环境产生交互（踩弯竹竿、踩碎石阶、炸开水花） |
| 惯性连续 | 禁止站桩或原地停顿，每2秒 ≥ 3米位移 |
| 残影规则 | 允许运动模糊残影，但仅本体产生碰撞和破坏 |
| 运镜配合 | 优先长镜头跟随 + 背景动态模糊增强速度感 |

---

## STEP 6：敌人调度（如群战）

| 要求 | 说明 |
|------|------|
| 站位明确 | 写了多少敌人就必须写多少站位和武器 |
| 同时行动 | 禁止回合制（一次打一个、其余等着） |
| 逻辑自洽 | 谁先出手、从哪个方向、用什么招、主角怎么应对 |
| 弓手/弩手 | 必须写弹道（从哪射出 → 经过什么 → 钉在哪），近距离禁止"完整拉弓实射" |

---

## STEP 7：自检（输出前逐条过）

### 时间检查
- [ ] 前2秒已有打斗接触？
- [ ] 激战期每2秒 ≥ 1次攻防交换？
- [ ] 慢镜头 ≤ 1次，在打斗中间？
- [ ] 史诗镜头 ≤ 1次，在7-10s，包含人物？

### 动作检查
- [ ] 无回合制站桩？
- [ ] 无"跑动蓄势"（应写滑步/垫步/切步/蹬转）？
- [ ] 武器无串位/断裂/变形/互换？
- [ ] 敌人有具体站位和动作？
- [ ] 弓手无近距离"完整拉弓实射"？

### 特写检查
- [ ] 战斗特写占比 ≥ 60%？
- [ ] 表情特写 ≤ 1次且 ≤ 0.3s？
- [ ] 每个特写含人体局部（非纯物品）？
- [ ] 环境特写由动作触发？

### 环境检查
- [ ] 每段有环境微反馈？
- [ ] 反馈由动作触发？
- [ ] 轻功有落点物理反馈？

## 附录 D：完整示例（15秒·剑门关栈道·顾栖月一对多）

```markdown
场景：剑门关夜间古栈道，贴崖木栈、石关门、旧旗、冷风穿关、火把摇晃、崖下深渊。35mm胶片颗粒，低调摄影暗调冷色。无字幕无水印无现代元素无神光符文。

人物：顾栖月，白色劲装，右手提白色剑鞘（剑未出鞘），左手持染血密信。轻功天下第一。
敌方：3名刀手从栈道前方7米处呈扇形逼来；2名弩手从右侧高处石门上方居高射箭；3名刀手从栈道后方5米处包抄。

## 第1段 [0-2s]｜信未拆·杀先至

**动作**：
- 顾栖月右脚蹬栈道木板向前滑步3米，同时左手将密信塞入衣襟，右手剑鞘横于身前
- 前方3名刀手同时拔刀冲出，最前方刀手挥刀劈向她头部
- 环境反馈：木板被蹬裂弹起木屑、火把被气流冲灭2根

**运镜**：中景侧跟
**特写**：[战斗] 刀锋劈下瞬间剑鞘格挡，金属碰撞火花溅在她手背上，≤0.3s

## 第2段 [2-5s]｜凌空·借栈夺位

**动作**：
- 顾栖月右脚踩上右侧栏杆借力向左45°弹起4米腾空，避开正面劈砍
- 2名弩手同时射箭，箭矢穿过她原来位置的木板（箭从右上和右中射出），钉入后方木柱
- 落地瞬间左脚尖点栈道边缘木板向右变向，右手剑鞘抽在左侧刀手手腕上
- 环境反馈：栏杆踩弯弹起、木板被箭穿透裂开、箭尾钉入木柱颤抖

**运镜**：低机位仰拍
**特写**：[环境] 弩箭钉入木柱、箭尾高频颤抖，≤0.2s

## 第3段 [5-8s]｜一剑·三杀·刃未清

**动作**：
- 顾栖月右手拇指推剑鞘露出三寸剑锋，左脚蹬前方刀手膝盖借力侧移
- 第一刀：剑尖划过右侧刀手喉口，横向切出0.4秒，血线浮现
- 第二刀：剑鞘压断左侧刀手持刀手腕，刀脱手旋转飞出栈道坠入深渊
- 第三刀：反手身后剑尖逼退后方包抄的刀手，那人踩空滑出栈道边缘
- 环境反馈：刀飞出旋转坠落深渊、血滴落在木板上

**运镜**：贴身短焦跟剑锋
**特写**：[战斗] 剑尖划过喉口瞬间血线浮现，0.3s慢放后极速回正

## 第4段 [8-10s]｜栈道全貌（史诗镜头）

**动作**：
- 顾栖月在栈道中央连续变位，剩余4名敌人被逼挤成一条线
- 两侧火把零星散落（已被打灭大部分），断裂木板悬空
- 已倒伏的刀手散落在栈道各处，深渊雾气从木板缝隙升起

**运镜**：大远景俯拍
**特写**：无（全景展示）

## 第5段 [10-13s]｜剑道·即栈道

**动作**：
- 顾栖月玉笛换左手吹出短音扰乱前方2人步点，右手持剑鞘横扫
- 剑鞘贴栈道栏杆掠过削掉薄层木花，经过残存火把时剑风将火焰切为两半
- 剑鞘尖点最后一人胸口，那人踩空滑出边缘，双手抓住木板悬在深渊上方
- 环境反馈：木花飞溅、火焰分裂、木板折断声在深渊中回荡

**运镜**：中景侧跟
**特写**：[战斗] 剑鞘尖点胸口瞬间，那人手指抓紧木板指关节发白，≤0.3s

## 第6段 [13-15s]｜收尾

**动作**：
- 顾栖月收回剑鞘，剑已归鞘。风吹衣袂，雪粉从断裂竹缝飘落
- 栈道上散落倒伏的敌人、断裂木板、熄灭的火把，深渊雾气升腾

**运镜**：缓拉中景
**特写**：无
```
