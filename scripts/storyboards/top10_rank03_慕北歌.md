# 《沸腾之雪》天榜十绝·天榜第03·慕北歌（15s）正式版

## 🎬 核心设计理念
- **视觉逻辑**：**“孤傲与透明”**。画面追求极致的干净。强调剑尖划过的空气真空痕迹。色彩以纯白、冰蓝、竹青为主。
- **动态节奏**：极简，去繁就简。动作如冰晶折射般不可捉摸，强调“切削”而非劈砍。
- **环境背景**：深山竹林，被暴雪覆盖。竹枝挂冰，空气仿佛被冻结。

## 🎥 镜头分解 (15s)

### 0.0-3.0s 【寂：白衣问雪】
- **景别**：远景 (LS) -> 侧脸特写。
- **画面**：慕北歌一身白衣立于弯曲的冰竹之上，竹身因重力微颤。镜头推向他手中的“问雪”，剑鞘如白犀角般温润。风雪吹过，他的发丝一动不动。
- **音效**：极度寂静中的冰裂声，微弱的寒风啸叫。

### 3.0-6.0s 【起：剑气空旋】
- **景别**：微距特写 (Macro CU)。
- **画面**：慕北歌拇指拨开剑格，透明的剑身出鞘。镜头捕捉到剑身周围的空气由于极低温产生了肉眼可见的折射波纹。雪花在触碰剑刃前，先被无形的锋芒整齐切开。
- **音效**：清冽的金属出鞘声，像冰块碰撞。

### 6.0-9.0s 【切：真空碎影】
- **景别**：中景 (MS) -> 升格。
- **画面**：面对围攻，慕北歌仅仅横向一抹。剑尖划过处，留下一道细长的透明空气槽。三名敌人的咽喉处在同一瞬间出现红线，伤口因极寒并未出血，而是直接封冻。
- **音效**：极细的高频切开声（Silk-cutting），ducking 3dB。

### 9.0-12.0s 【落：冰裂回响】
- **景别**：地面特写。
- **画面**：慕北歌落地，脚尖轻点雪面。周围数米内的竹叶冰凌由于剑气的余波，在同一时间全部崩碎落下。画面呈现极致的晶莹感。
- **音效**：万千冰晶落地的清脆声响，如碎铃。

### 12.0-15.0s 【定：剑归寂灭】
- **景别**：全景 (FS)。
- **画面**：慕北歌还剑入鞘，背影与漫天风雪融为一体。画面定格在**【寂】**字视觉符号上。
- **音效**：沉重的还剑入鞘声“咔”，余音悠长。

## 📝 技术 specifications
- **规格**：2.39:1 / 24fps / 4K。
- **色彩规范**：冰蓝色、纯白、冷灰。
- **物理反馈**：剑气切削要通过空气折射体现，伤口封冻的质感需符合写实逻辑。
