# 《沸腾之雪》天榜十绝·天榜第十·燕照绫（15s）正式版

## 🎬 核心设计理念
- **视觉逻辑**：写实高武，强调物理力学反馈。通过大漠风沙的荒凉感与钢节长鞭的金属质感形成对比。
- **动态节奏**：连续作战，鞭法如赤蛇游走，强调“点-拉-崩”的爆发力。
- **环境背景**：关外大漠古驿道（残烽火台、断旗、风蚀岩、沙暴边缘）。

## 🎥 镜头分解 (15s)

### 0.0-2.2s 【开势：沙海鞭鸣】
- **景别**：低机位贴沙推进 (Low-angle Tracking)。
- **画面**：燕照绫半转身抬腕，钢节长鞭“赤练”拖在沙地划出弧线，摩擦出细微火花。鞭梢“啪”地一声抽向前方，强劲的力道震碎了一层贴地风沙。
- **音效**：风沙呼啸声中夹杂着沉重的金属拖地声，随后是一声清脆的鞭爆。

### 2.2-4.4s 【变：西燕围杀】
- **景别**：中景 (MS)。
- **画面**：敌首抱拳：“公主，大将军不在，请你暂时不要出西燕。”话音未落猛然挥手。8名西燕刀手瞬间压上：3名前压、3侧切、2后偷袭，死封所有退路。
- **音效**：风沙声瞬息减弱（突出台词），随即被杂乱的拔刀声与脚步声填满。

### 4.4-6.8s 【破：第一轮阵】
- **景别**：特写 (CU) -> 中景 (MS)。
- **画面**：燕照绫立而不退，身形下沉完成“低扫膝”。赤练鞭反向回抽完成“回鞭锁腕”，将正前方敌首猛力掼进残破木桩；侧踹击退第二人，鞭节顺势缠绕住第三人的刀锋，使其失衡。
- **音效**：密集的金属碰撞声，木材崩裂的钝响，重物坠沙声。

### 6.8-9.4s 【切：侧翼反制】
- **景别**：升格摄影 (High-speed)。
- **画面**：两侧刀手杀到，燕照绫脚点断裂车辕借力腾起，空中拧腰横鞭。赤练先重击左侧刀背，借势后抽击中右侧敌方肋线。两人翻滚入沙，燕照绫落地瞬间，鞭尾如蛇吐信，点住后排偷袭者的咽喉。
- **音效**：沉闷的肋骨受击声，风沙被鞭势划破的尖锐声。

### 9.4-12.0s 【绞：近身止戈】
- **景别**：环绕镜头 (Orbital Shot)。
- **画面**：赤练展现“缠-锁-拉-崩”四连动作。缠绕刀身、锁死手臂、暴力拉扯位移、最后鞭节炸裂式崩击。火星溅射、布料抽风颤动、沙粒随打击方向爆散。敌阵被彻底撕碎。
- **音效**：连贯的鞭鸣声，高频的金属摩擦声，敌人的闷哼声。

### 12.0-13.4s 【杀：百步锁魂】
- **景别**：远景 (LS) -> 极速推进。
- **画面**：燕照绫甩出鞭头，钉入半埋的石柱作锚点，旋身二周半，赤练横扫中轴。最后三名刀手同线中招，如断线风筝倒飞，撞碎后方的残旗架。
- **音效**：鞭头入石的清脆撞击，旗架崩塌的轰鸣。

### 13.4-15.0s 【离：风沙远影】
- **景别**：全景 (FS) -> 逐渐后拉。
- **画面**：燕照绫收鞭入怀，不看地上的伤者，翻身上马。骏马沿驿道疾驰而去。镜头后拉定格：残旗在烈风中猎猎作响，战场逐渐被漫天大雪与风沙吞没。
- **音效**：急促的马蹄声逐渐远去，最终只剩下纯粹的风沙咆哮。

## 📝 技术 specifications
- **画幅**：2.39:1 / 24fps。
- **影调**：35mm胶片颗粒感，电影级写实自然光影，高对比度。
- **旁白（可选，说书人口吻）**：“关外那夜，赤练一舞，八刀尽折。从此天榜第十，燕照绫。”
